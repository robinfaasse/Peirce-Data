This operation is obviously commutative:
(70) If x ƚ y, then necessarily y ƚ x.
It is not associative. On the contrary, we have
(71) x ƚ (y ƚ z) = x ⤄ y · z = (x ⤄ y) · (x ⤄ z),
(72) (x ƚ y) ƚ z = x · y ⤄ z = (x ⤄ z) · (y ⤄ z).
(73) If x · (y ƚ z), then necessarily (x ⤄ y) ƚ z,
(74) If (x ƚ y) · z, then necessarily x ƚ (y ⤄ z).
