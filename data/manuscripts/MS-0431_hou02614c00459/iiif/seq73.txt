A [u]function[/u] is said to be a quantity whose value depends upon
the value of another or others, called its [u]arguments[/u]. It is usual
to say that the [u]arguments[/u] vary, each of them through the whole
range of possible values; and for each set of possible values
of the arguments the function has one or more values, al-
ways [ins](for a [u]regular[/u] function)[/ins] the same number, except when two or more coincide.
The function and arguments are, therefore, called [u]variables[/u];
the latter independent variables, the latter a variable dependent
upon them. Moreover, for a regular function, for any one
[ins]set of[/ins] values of the function and of all its arguments but one,
there is the same number of possible values of the remaining
argument. By "varying", the mathematician does not neces-
