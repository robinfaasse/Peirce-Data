[u]Demonstration[/u]. I have to prove that [u]ax + bx + cx + etc.[/u]
has the same value as [u](a x + b x + c x + etc.) · x[/u] [ins]and also[/ins] [del]and further[/del]
the same value as [u](a + b + c + etc.) · x[/u].

First, suppose that the value of [u]ax + bx + cx + etc.[/u] is [u]v[/u].
Then, by the third clause of the definition of composition, the value of
[u](a x + b x + c x + etc.) · (a x + b x + c x + etc.)[/u] will also be [u]v[/u].
But then, omitting components, [u](a x + b x + c x + etc.) · (x · x · x · etc)[/u]
will also be [u]v[/u]. But then, [u](a x + b x + c x + etc.) · x[/u] will be [u]v[/u].
