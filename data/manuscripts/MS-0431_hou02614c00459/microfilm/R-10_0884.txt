When one set of values only is admitted, we need some way for expressing, at once, [del]the[/del] [ins]no[/ins] point of the same state of things, that one of the quantities, say [u]x[/u], has a certain value, and that the other, say [u]y[/u], has a certain value. The best way is to use a heavy dot, and write in the four cases

* The most complete information we can have about a pair of quantities [u]x[/u] and [u]y[/u], is that every set of values is impossible, so that there are no such quantities. This often results as the solution of a problem.
† This is no information at all.
