Rule for addition. First set down A. Count the number of A's following B's Divide by 2. [del]Set down remainder by further[/del] If remainder is odd set down B to left of A if even to right. Carrying quotient add with the number of A's and B's to right of C's. Divide sum by 3. [del]If[/del] According as remainder is 0, 1, 2, set down C with 0, 1, 2 of the letters A and B to the right of it. And so on.
