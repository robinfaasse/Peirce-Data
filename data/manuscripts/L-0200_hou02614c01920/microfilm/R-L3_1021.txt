Mark every place
$\frac{0}{1} < \left| \frac{1}{1} \right| < \left| \frac{2}{1} \right| < \left| \frac{3}{1} \right| < \left| \frac{4}{1} \right|$
$\frac{0}{1} > \left| \frac{1}{1} \right| > \left| \frac{1}{2} \right| > \left| \frac{1}{3} \right| > \left| \frac{1}{4} \right| > \left| \frac{1}{5} \right|$

Insert the 2s thus
$\frac{0}{1} = \frac{0}{2} < \frac{1}{2} < \frac{1}{1} = \frac{2}{2} < \frac{3}{2} < \frac{2}{1} = \frac{4}{2} < \frac{5}{2} < \frac{3}{1} = \frac{6}{2} < \frac{7}{2} < \frac{4}{1}$
$\frac{0}{1} = \frac{0}{2} > \frac{2}{1} > \frac{1}{1} = \frac{2}{2} > \frac{2}{3} > \frac{1}{2} = \frac{2}{4} > \frac{2}{5} > \frac{1}{3} = \frac{2}{6} > \frac{2}{7} > \frac{1}{4} = \frac{2}{8} > \frac{2}{9}$

Mark every $2^{\text{nd}}$ place
$\frac{0}{1} = \left\{ \frac{0}{2} \right\} < \left| \frac{1}{2} \right| < \frac{1}{1} = \left\{ \frac{2}{2} \right\} < \left| \frac{3}{2} \right| < \frac{2}{1} = \left\{ \frac{4}{2} \right\} < \left| \frac{5}{2} \right| < \frac{3}{1} = \left\{ \frac{6}{2} \right\} < \left| \frac{7}{2} \right| <$
$\frac{0}{1} = \left\{ \frac{0}{2} \right\} > \frac{2}{1} > \frac{1}{1} = \left\{ \frac{2}{2} \right\} > \left| \frac{2}{3} \right| > \frac{1}{2} = \left\{ \frac{2}{4} \right\} > \left| \frac{2}{5} \right| > \frac{1}{3} = \left\{ \frac{2}{6} \right\} > \left| \frac{2}{7} \right| >$

Insert the 3s thus:
$\frac{0}{1} = \frac{0}{3} = \frac{0}{2} < \frac{1}{3} < \frac{1}{2} < \frac{2}{3} < \frac{1}{1} = \frac{3}{3} = \frac{2}{2} < \frac{4}{3} < \frac{3}{2} < \frac{5}{3} < \frac{2}{1} = \frac{6}{3} = \frac{4}{2} < \frac{7}{3} < \frac{5}{2} < \frac{8}{3} <$

Mark every $3^{\text{rd}}$ place thus
$\frac{0}{1} = \frac{0}{3} = \frac{0}{2} < \left| \frac{1}{3} \right| < \frac{1}{2} < \left| \frac{2}{3} \right| < \frac{1}{1} = \frac{3}{3} = \frac{2}{2} < \left| \frac{4}{3} \right| < \frac{3}{2} < \left| \frac{5}{3} \right| < \frac{2}{1} = \frac{6}{3} = \frac{4}{2} < \left| \frac{7}{3} \right| < \frac{5}{2} <$

Insert the 4s thus:
$\frac{0}{1} = \frac{0}{3} = \frac{0}{4} = \frac{0}{2} < \frac{1}{4} < \frac{1}{3} < \frac{1}{2} = \frac{2}{4} < \frac{2}{3} < \frac{3}{4} < \frac{1}{1} = \frac{3}{3} = \frac{4}{4} = \frac{2}{2} < \frac{5}{4} < \frac{4}{3} < \frac{3}{2} = \frac{6}{4} < \frac{5}{3} < \frac{7}{4} <$

Mark every $4^{\text{th}}$ place
$\frac{0}{1} = \frac{0}{3} = \left| \frac{0}{4} \right| = \frac{0}{2} < \left| \frac{1}{4} \right| < \frac{1}{3} < \frac{1}{2} = \left| \frac{2}{4} \right| < \frac{2}{3} < \left| \frac{3}{4} \right| < \frac{1}{1} = \frac{3}{3} = \left| \frac{4}{4} \right| = \frac{2}{2} < \left| \frac{5}{4} \right| < \frac{4}{3} < \frac{3}{2} = \left| \frac{6}{4} \right| < \frac{5}{3}$

Insert the 5s thus
$\frac{0}{1} = \frac{0}{3} = \frac{0}{5} = \frac{0}{4} = \frac{0}{2} < \frac{1}{5} < \frac{1}{4} < \frac{1}{3} < \frac{2}{5} < \frac{1}{2} = \frac{2}{4} < \frac{3}{5} < \frac{2}{3} < \frac{3}{4} < \frac{4}{5} < \frac{1}{1} = \frac{3}{3} = \frac{5}{5} = \frac{4}{4} = \frac{2}{2} < \frac{6}{5} < \frac{5}{4}$

Mark every $5^{\text{th}}$ place
$\frac{0}{1} = \frac{0}{3} = \frac{0}{5} = \frac{0}{4} = \frac{0}{2} < \left| \frac{1}{5} \right| < \frac{1}{4} < \frac{1}{3} < \left| \frac{2}{5} \right| < \frac{1}{2} = \frac{2}{4} < \left| \frac{3}{5} \right| < \frac{2}{3} < \frac{3}{4} < \left| \frac{4}{5} \right| < \frac{1}{1} = \frac{3}{3} = \frac{5}{5} = \frac{4}{4} = \frac{2}{2} < \left| \frac{6}{5} \right| < \frac{5}{4}$

Insert the 6s thus
$\frac{0}{1} = \frac{0}{3} = \frac{0}{5} = \frac{0}{6} = \frac{0}{4} = \frac{0}{2} < \frac{1}{6} < \frac{1}{5} < \frac{1}{4} < \frac{1}{3} = \frac{2}{6} < \frac{2}{5} < \frac{1}{2} = \frac{3}{6} = \frac{2}{4} < \frac{3}{5} < \frac{2}{3} = \frac{4}{6} < \frac{3}{4} < \frac{4}{5} < \frac{5}{6} < \frac{1}{1} = \frac{3}{3} = \frac{5}{5} = \frac{6}{6} = \frac{4}{4}$

We see that, owing to the great number of signs of equality near fractions of low
denomination the values of rational fractions are thinly scattered
in those neighborhoods.
