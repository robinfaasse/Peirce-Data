[pn]44[/pn] [pn]4th[/pn] 4=, If there be anything that which nothing else can
be more certain, it would seem to be that there really is
such a thing as error. For if it were not so, nothing could be
more certain anything else, and consequently nothing
could be more certain than that there is error.

On the other hand, it might be argued that not every
possible assertion can be false, since since if it were so,
the assertion that it was so would be false. [ins]that argument[/ins] But supposes
[fig]black circle[/fig] that if it were so, that assertion would be possible. All
that seems to be proved is that if every assertion be false,
it must be impossible to say so. It certainly does seem
impossible to say so sincerely. In other words, it seems im-
possible to opine that every possible opinion is false.
