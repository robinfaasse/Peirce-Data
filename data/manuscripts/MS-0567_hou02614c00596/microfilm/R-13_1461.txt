Among the particular applications constantly

$$a + b = a + \overline{a} b$$
$$(a b + \overline{a} \overline{b}) = (a + \overline{b}) (\overline{a} + b)$$
$$(a + b) c \prec a + b c$$
$$(a + x) (b + y) \prec a + b + x y.$$

From the last formula but one, which is
not itself a distribution-formula but an
association-formula, all the distribution-
