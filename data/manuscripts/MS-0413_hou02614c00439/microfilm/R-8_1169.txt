§132. The moods which we have thus far considered are all
that were recognized by Aristotle. His immediate successor
Theophrastus, besides calling Darapti two moods, introduced
five others here shown.

[u]Baralipton[/u].
Any X is Y,
Any Z is X;
∴ [del]Some[/del] [ins]Any[/ins] Y is Z.

[u]Fapesmo[/u]
Any X is Y,
Any Z is not X;
∴ Some Z is not Y.

[u]Dabitis[/u]
Any X is Y,
Some Z is X;
∴ Some Y is Z

[u]Frisesomorum[/u]
Some X is Y,
Any Z is not X;
∴ Some Y is not Z.

[u]Celantes[/u]
Any X is not Y,
Any Z is X;
∴ Any Y is not Z.
