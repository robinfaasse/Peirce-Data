[del]sumed as logically necessary,[/del]
[del]Some N is some N[/del]
[del]is not so. What is necessary is[/del]
Some-N is some-N,
which differs from the preceding in not asserting that
there is any N. Our inference is therefore to be corrected
as follows:
If there is any N, some N is some-N,
All N is M,
$\therefore$ If there is any M, some M is some-N;
i.e. Some-M is some-N.

The inference
Any N is M,
$\therefore$ Some M is N,
is called the conversion of A [del]per accidens[/del]. In my system
of propositions, it does not hold, but the inference
above
Any N is M
$\therefore$ Some-M is some-N (i.e. the only N)
fulfills its function. I term this inference [u]lectical contra-[/u]
[u]position[/u].
