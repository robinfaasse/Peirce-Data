[u]Proof[/u]. [u]First[/u], there is, by the first condition, a number which is 0+0; but there is no other, for [del]next[/del] the first condition necessitates no other number than 0 to be 0+0, and the second and third conditions necessitate no number to be a sum unless either the number added or the number added to is G to a number. But, by the second precept, 0 is G to no [ins]cardinal[/ins] number. Hence, by the fourth condition no number except 0 is 0+0.

[u]Second[/u], whatever cardinal number N may be, there is a number which is 0+N. For if N is zero, this is true by the first condition. But if there be any number, N, of which this is true, then by the second condition, it is true of GN. Hence, by the Fermatian Principle it is true of every number. But there is but one number which is 0+N. For the first and second conditions necessitate but one number to be so. For they necessitate but one number to be so when N=0 and if they only necessitate but one number to be 0+N they necessitate but one number to be 0+GN since by the second general corollary there is but one number which is G(0+N) if there is but one number which is 0+N. Hence by the Fermatian Principle, but one number is necessitated to be 0+N and hence by the [del]4th[/del] [ins]th[/ins] condition but one number is 0+N.
