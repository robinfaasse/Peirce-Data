[del]25[/del] [ins]25[/ins] [u]Definition 2[/u]. [del]The[/del] [ins]A[/ins] sum of a cardinal number, M, added to [del]a[/del] cardinal number, N, is a cardinal number which fulfills the following conditions:

1[sup]st[/sup], A sum of zero added to zero [ins]is zero[/ins];

2[sup]nd[/sup], A sum of zero added to a cardinal number which is G to any cardinal number [ins]N,[/ins] is a number which is G to a sum of zero added to N;

3[sup]rd[/sup], A sum of a cardinal number that is G to any cardinal number, M, added to any cardinal number, N, is a [ins]cardinal[/ins] number which is G to a [ins]cardinal[/ins] number which is a sum of M added to N;

4[sup]th[/sup], No cardinal number is a sum of a cardinal number added to a cardinal number unless it is necessitated to be so by the above conditions.

[del]26[/del] [ins]26[/ins] [u]Abbreviations[/u]. The character = expresses that the [ins]cardinal[/ins] number before it is the same as the cardinal number written after it.

The character > expresses that the cardinal number that is written before it is greater than the cardinal number that is written after it.

G together with a cardinal number [ins]N[/ins] written after it [ins]as G N,[/ins] denotes a number that is G to N. By the second general corollary, there is but one such number.

The character + together with the numbers written before and after it denotes a number which is a sum of the number written before it added to the number written after it.
