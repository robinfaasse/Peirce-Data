[u]Proof[/u]. Let N be a cardinal number which has this character that either N = 0 or taking any two different cardinal numbers L and M, such that L > M, L·N > M·N. Then L·GN = L + L·N and M·GN = M + M·N. Since therefore L > M and either N = 0 or L·N > M·N, it follows that L·GN > M·GN and GN has the character. Zero manifestly has it. Hence, etc.

[u]Corollary 1[/u]. If L > M, N·L > N·M unless N = 0.

[u]Corollary 2[/u]. If A > C and B > D, A x B > C x D in all cases.

[u]Corollary 3[/u]. Unless L = M, L x N is not M x N, unless N = 0.

[u]Corollary 4[/u]. If L x N > M x N, then L > M in all cases.

[u]Corollary 5[/u]. If A x B > C x D, either A or B is greater than C and than D or C or D is less than A and than B.
