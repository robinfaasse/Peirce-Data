Derived from
$l_{\infty} = l b + l \bar{b}$
we have $l_{b} = l b + l_{0}$ etc.

$$l^{b} \prec l b + 0^{b} \qquad l^{b}_{b} \prec l b + 0^{0}_{b}$$
$$l^{b} \prec l \text{ o } b + l^{\infty} \qquad l^{b}_{b} \prec l \text{ o } b + l^{\infty}_{b}$$

[del]$\dagger$[/del]
$$\infty \times l^{b} \prec l b \qquad \infty \times l^{b}_{b} \prec l b$$
$$l \text{ o } \times l^{b} \prec l \text{ o } b \qquad l \text{ o } \times l^{b}_{b} \prec l \text{ o } b$$
