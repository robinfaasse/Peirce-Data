Some A is not some B (1)
Some C is not some B (2)
$\therefore$ Some C is not something (2) that is not something (1) that is
not some A.

[fig]Venn diagram with three intersecting circles labeled a, b, c[/fig]

Some A is B
Some B is C
$\therefore$ Some A is coexistent with some C; i.e. There is some A;
there is some C.
