It will necessarily be so in every case. Thus, if the proposition holds for all consequences having fewer than any given number, N, of proximate antecedental[ins]s[/ins], it [del]is[/del] [ins]holds[/ins] good for every proposition having no more than, N, proximate antecedentals, and therefore for every proposition having a number of proximate antecedentals that can be reached by successive additions of unity to N. But it is identically true when there is no antecedental, and is true by (64) when there is but one. Hence, it is true for any finite number of antecedentals, that is, for any consequence which can be written out; for the writing out has to be done antecedental by antecedental.

This mode of reasoning about finite collections, called Fermat's reasoning, need not be stated at full length
