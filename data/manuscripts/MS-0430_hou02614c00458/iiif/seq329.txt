5[ins]th[/ins], Knowing that [u]v[/u] is [u]a[/u], we can say that [u]v[/u] is EITHER [u]a[/u] OR [u]b[/u]. Equally, knowing that [u]v[/u] is [u]b[/u], we can say that [u]v[/u] is [del]&[/del] EITHER [u]a[/u] OR [u]b[/u]. For the [u]a[/u] and [u]b[/u] are on a par, each with the other. [ured]It is the same to say that EITHER v is a OR v is b.[/ured]
([ins]This does not hold when in place of v we put ‘every member of a class’[/ins])

6[ins]u[/ins], Knowing that [u]v[/u] is [u]b[/u], we can say that [u]v[/u] is IF [u]a[/u] THEN [u]b[/u].
[ured]It is the same to say, IF v is a, THEN v is b.[/ured]
(This is not so, when if is used, as it commonly is, to mark a necessary assertion. What is here meant is that if [u]v[/u] is [u]a[/u], then it happens to be [u]b[/u]. A necessary assertion has regard to a whole range of possibilities, a conditional de inesse considers only the actual state of things; so that to say, IF [u]v[/u] is [u]a[/u], THEN [ins][u]v[/u] is[/ins] [u]b[/u], merely means, [u]Unless [u]v[/u] is [u]a[/u], [u]v[/u] is [u]b[/u].[/u])

7[ins]th[/ins], Knowing that [del]is[/del] [u]v[/u] is EITHER [u]a[/u] OR [u]b[/u] and knowing that [u]v[/u] is IF [u]a[/u], THEN [u]b[/u], we know that [u]v[/u] is [u]b[/u].

Thus [del]know[/del] [ins]knowing[/ins] either of the propositions, [u]v[/u] is [u]b[/u] and [u]v[/u] is BOTH EITHER [u]a[/u] OR [u]b[/u] AND IF [u]a[/u] THEN [u]b[/u], we know the other; so that they are equivalent.
