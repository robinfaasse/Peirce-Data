(7 [ins](74)[/ins]) If x ~ x ~ y is true, x ~ y is true.
For by (65) if x ~ x ~ y is true, either x is false or x ~ y
is true, and if x ~ y is true, [del]either x is false or y is true[/del]
But by (67) if x is false x ~ y is true. Hence, (74). That is, a
[del]repeated[/del] repetition of an antecedent is of no effect; for by (66)
if x ~ y is true, x ~ x ~ y is true; so that x ~ y and x ~ x ~ y are
equivalent.
