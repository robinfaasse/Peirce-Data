Theorem I. The algebraical consequence x x y implies

(73) 1st, that if x is scriptible then both x and y are applicable
(74) to v jointly; and if v is individual, the consequence is equivalent to this conditional proposition;

(75) 2nd, that, if [del]either[/del] [ins]then[/ins] x or y is applicable to v distributively,
(76) [del]then[/del] y is scriptible; and if v is definite, the consequence is equivalent to this proposition;

(77) 3rd, that, if x is scriptible, so is y; and if v is both
(78) individual and definite, the consequence is equivalent to this proposition.
