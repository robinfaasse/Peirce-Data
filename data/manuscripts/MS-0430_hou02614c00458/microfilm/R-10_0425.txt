(78) If [u]x[/u] and [u](x < y)[/u] and [u](y < z)[/u] are true, [u]z[/u] is true.
For, by (77), is [u]x[/u] and [u](x < y)[/u] are true, [u]y[/u] is true; and if
[u]y[/u] and [u](y < z)[/u] are true, [u]z[/u] is true. Hence, (78)

(79) If [u](x < y)[/u] and [u](y < z)[/u] are true, [u](x < z)[/u] is true.
For, by (78), if [u](x < y)[/u] and [u](y < z)[/u] are true, then if [u]x[/u] is
true, [u]z[/u] is true; when, by (64), [u](x < z)[/u] is true. Whence, (79).
This is the principle of [del]Barbara[/del] [ins]Barbara[/ins].

(80) If [u]x < y[/u] is true, then [u](y < z) < (x < z)[/u] is true.
For, by (79), if [u](x < y)[/u] is true, then if [u](y < z)[/u] is true [u](x < z)[/u]
is true; when by (64), [u](y < z) < (x < z)[/u] is true. This is the
[u]Rule of Contraposition[/u].

(81) If [u](x < y) < z[/u] is true, [u]y < z[/u] is true
This follows from (66) by contraposition.

(82) [del]If[/del] [u][(y < x) < z] < (x < y) < z[/u].
This follows by (71) by contraposition.

(83) If [u](y < x < z) < t[/u] is true, [u](x < y < z) < t[/u]
This follows from (82) by (65). This supplements the rule of transposition,
showing that antecedents whatever they are antecedents are transponible.
