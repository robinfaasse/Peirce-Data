$5^{\text{th}}$, Knowing that $\underline{\text{v}}$ is $\underline{\text{a}}$, we can say that $\underline{\text{v}}$ is EITHER $\underline{\text{a}}$
or $\underline{\text{b}}$. Equally, knowing that $\underline{\text{v}}$ is $\underline{\text{b}}$, we can say that $\underline{\text{v}}$ is
EITHER $\underline{\text{a}}$ OR $\underline{\text{b}}$. For the $\underline{\text{a}}$ and $\underline{\text{b}}$ are on a par, each
with the other. If it the same to say that EITHER $\underline{\text{v}}$ is $\underline{\text{a}}$ OR $\underline{\text{v}}$ is $\underline{\text{b}}$.
(This does not hold when in place of $\underline{\text{v}}$ we put "every member of a class".)

$6^{\text{th}}$, Knowing that $\underline{\text{v}}$ is $\underline{\text{b}}$, we can say that $\underline{\text{v}}$ is IF $\underline{\text{a}}$ THEN $\underline{\text{b}}$.
If is the same to say, "IF $\underline{\text{v}}$ is $\underline{\text{a}}$, THEN $\underline{\text{v}}$ is $\underline{\text{b}}$."
(This is not so, when if is used, as it commonly is, to
mark a necessary assertion. What is here meant is that if
$\underline{\text{v}}$ is $\underline{\text{a}}$, then it happens to be $\underline{\text{b}}$. A necessary assertion has
regard to a whole range of possibilities, a conditional de inesse
considers only the actual state of things; so that to say, "IF $\underline{\text{v}}$ is $\underline{\text{a}}$, [ins]$\underline{\text{v}}$ is[/ins] THEN $\underline{\text{b}}$",
merely means, "Unless $\underline{\text{v}}$ is $\underline{\text{a}}$, $\underline{\text{v}}$ is $\underline{\text{b}}$.")

$7^{\text{th}}$, Knowing that [del]$\underline{\text{v}}$ is[/del] $\underline{\text{v}}$ is EITHER $\underline{\text{a}}$ OR $\underline{\text{b}}$ and knowing
that $\underline{\text{v}}$ is IF $\underline{\text{a}}$, THEN $\underline{\text{b}}$, we know that $\underline{\text{v}}$ is $\underline{\text{b}}$.

[del]Thus[/del] [ins]Knowing[/ins] either of the propositions, $\underline{\text{v}}$ is $\underline{\text{b}}$ and $\underline{\text{v}}$ is BOTH
EITHER $\underline{\text{a}}$ OR $\underline{\text{b}}$ AND IF $\underline{\text{a}}$ THEN $\underline{\text{b}}$, we know the other; so
that they are equivalent.
