(27) If [u]x ≺ x ≺ x[/u] is only then is [u]x ≺ x[/u] true.

For by (59) if [u]x ≺ x[/u] is true, [u]x[/u] is only true if [u]x ≺ x[/u] is true.

But if [u]x[/u] is false, by (27), [u]x ≺ x[/u] is true. This is a repeated antecedent may be dropped.
