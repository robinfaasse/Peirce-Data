If A had said of B, "If there be any real meaning in
what he says there is falsity in it," and B had said the
same thing of C, and C of A, it might be argued that
since they none of them have any real meaning, all
that they say is quite true, and has that much real
meaning; so that they all three testimonies are
false. But all such endless contradictions only illustrate
how unreal is any assertion which does not bring up upon
something which is as it is whether it is asserted to be
so or not. So too in regard to the proposition "This very pro-
position has some real meaning"; if you say that it is
false, it cannot be false so unless it means something;
so that you are landed in contradiction. If you say that
it has real meaning you are involved in no contra-
diction. For the former statement is true and
the latter false. Suppose that on a blank sheet of
