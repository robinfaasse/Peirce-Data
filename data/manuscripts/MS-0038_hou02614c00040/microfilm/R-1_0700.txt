2. To prove the commutative principle of addition that
$$x + y = y + x$$
whatever numbers $x$ and $y$ may be. First, it is true for $x = 1$ and $y = 1$, being in that case an explicit identity. Second, if true for $x = n$ and $y = 1$, it is true for $x = 1 + n$ and $y = 1$. That is, if $n + 1 = 1 + n$, then $(1 + n) + 1 = 1 + (1 + n)$. For $(1 + n) + 1$
$$= 1 + (n + 1)$$ by the associative principle:
$$= 1 + (1 + n)$$ by hypothesis.

We have thus proved that, whatever number $x$ may be, $x + 1 = 1 + x$, or that $x + y = y + x$ for $y = 1$. It is now to be shown that if this be true for $y = n$, it is true for $y = 1 + n$; that is, if $x + n = n + x$, then $x + (1 + n) = (1 + n) + x$. Now,
$$x + (1 + n)$$
$$= (x + 1) + n$$ by the associative principle:
$$= (1 + x) + n$$ as just seen:
$$= 1 + (x + n)$$ by the definition of addition:
$$= 1 + (n + x)$$ by hypothesis:
$$= (1 + n) + x$$ by the definition of addition.

Thus the proof is complete.
