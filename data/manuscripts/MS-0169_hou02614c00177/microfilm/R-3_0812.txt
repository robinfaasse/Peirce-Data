The relationship between the different numerals of one series in respect to the operation of counting is as follows:

1[sup]st[/sup], No two [ins]different[/ins] numerals of the series suppose each other. [[del]Two vocables neither of which is ever used without the other in counting would [ins]together[/ins] amount to a single numeral[/del]]

2[sup]nd[/sup], Among [del]the numerals,[/del] [ins]any select set of as well as among all there are in the series,[/ins] [del]of any part of the whole of the series[/del] there is one which is "supposed" by every one of them. [I.e. there is one which is used in [del]any[/del] [ins]every[/ins] count in which any of them is used]

3[sup]d[/sup], Any set of numerals of the series is either such that there is one among them which supposes them all, or is such that [del]whatever[/del] [ins]every[/ins] numeral of the whole series, and not merely [ins]every one[/ins] of this set, [del]is considered, that[/del] is supposed by some numeral of the set. [I.e. there is either one of the set which [del]as[/del] [ins]will[/ins] never be used unless all the others are used, or else there is no numeral of the whole series which is only used when all the numerals of the set are used.]
