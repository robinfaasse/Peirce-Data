<u>Definition 2</u>. An enumerable collection is a collection [ins]of[/ins] which every
object is in every relation to some object of that collection which relation
is that of a semicorrespondence in which the collection stands to itself.
That is, it is such a collection that (8) is true of it.

A collection not enumerable is inenumerable.

<u>Art. 3. Scholium 2</u>. An inenumerable [del]relation[/del] [ins]collection[/ins] can be in
semicorrespondence to a collection of which it forms a part;
but it is not necessarily in semicorrespondence to every col-
lection of which it forms a part. The question therefore arises whether
there be any sort of [fig]ink blot[/fig] collection which is in semicorrespond-
ence with every collection, without embracing the whole universe.
