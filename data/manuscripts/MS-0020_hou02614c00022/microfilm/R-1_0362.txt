On the other hand, were we to drop the premise which enumerates the collection [u]m[/u], it is plain that merely from that which expresses that [u]m[/u] is a part of [u]n[/u] $\bar{s}_{mn}$ would not logically follow. This corrects a gross error of logic into which most people fall. It thus appears that, in order to necessitate $\bar{s}_{mn}$ it is not only necessary that [u]m[/u] should be a part of [u]n[/u] of something from which [u]n[/u] proceeds, but also that it should possess some character independent of [u]n[/u].

[u]Problem 1[/u]. [u]Required that character of a collection, m, which will render it impossible that it should proceed from a collection of which it forms a part[/u].

[u]Solution[/u]. The condition that [u]m[/u] is a part of [u]n[/u] is expressed by

$\Pi_u \bar{q}_{mu} + q_{nu}$ $\Sigma_v q_{nv} \cdot \bar{q}_{mv}$

We may write this in the abridged form $P_{mn}$. Writing X for the unknown character sought, we have

$P_{mn} \cdot X_m \prec \bar{s}_{mn}$.
