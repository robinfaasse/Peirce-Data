[u]Corollary 53[/u]. ([u]The Test of Proportions[/u].) Four rational quantities, not zero nor infinite, of which the product of the first and fourth equals that of the second and third, are proportioned, the first to the second, as the third to the fourth. For supposing
$$AD = BC,$$
on multiplying by $\frac{1}{BD}$, we get, by Definition 59,
$$\frac{A}{B} \cdot \frac{D}{D} = \frac{B}{B} \cdot \frac{C}{D}$$
But $\frac{B}{B} = \frac{D}{D} = 1$, if neither B nor D is 0 nor $\infty$, so that by
$$\frac{A}{B} = \frac{C}{D},$$
i.e.
$$A : B :: C : D.$$

[u]Corollary 54[/u]. If
$$A : B :: C : D,$$
then
$$A : C :: B : D,$$
$$D : C :: B : A,$$
$$D : B :: C : A.$$
Thus, four different proportions coexist. They are illustrated in this diagram
$$A : B$$
$$::$$
$$C : D$$
where the proportion holds in [del]either[/del] [ins]the same[/ins] direction along any two opposite sides of the square.
