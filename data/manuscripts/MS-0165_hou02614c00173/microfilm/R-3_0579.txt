[u]Corollary[/u] 120. It follows from the reasoning of the last
Scholium that we may begin with any four points in
a plane, [A], [B], [C], [D], which we may suppose
subject to an equation
[del][A][/del]
[u]a[/u] A + [u]b[/u] B + [u]c[/u] C + [u]d[/u] D = 0
where [u]a[/u], [u]b[/u], [u]c[/u], [u]d[/u] are numbers.

And from these we at once find three other points:
[u]First Point[/u]: [u]a[/u] A + [u]b[/u] B = [u]c[/u] C + [u]d[/u] D [del]([/del]or = - ([u]c[/u] C + [u]d[/u] D); but
we do not distinguish a point from a multiple of it.[del])[/del]
[u]Second Point[/u]: [u]a[/u] A + [u]c[/u] C = [u]b[/u] B + [u]d[/u] D
[u]Third Point[/u] [u]a[/u] A + [u]d[/u] D = [u]b[/u] B + [u]c[/u] C.

Or, to avoid [del]needless[/del] doubling of the letters, call the
points
A + B = C + D
A + C = B + D
B + C = A + D
