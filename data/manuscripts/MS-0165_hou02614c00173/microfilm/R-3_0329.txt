[u]Scholium II[/u]. If the function has two variables, it may be defined by a [ins]general[/ins] rule showing the effect of varying one of the variables anywhere, with [del]another[/del] [ins]one or[/ins] more particular rules showing the effect of varying the other variable when the first has [del]a[/del] [ins]one or more[/ins] particular values, and finally a certain number of special values of the function for special [ins]pairs of[/ins] values of the variables.

A good way of conceiving of the matter is, to imagine an indefinitely extended table of double-entry, that is, a table on the general plan of a multiplication-table. Imagine that there is a [del]column[/del] [ins]horizontal[/ins] row for each value of the first variable, and a column for each value of the second variable, and [ins]that[/ins] the value of the function is found in the square where the row and column intersect.

Now, it is obvious, that if we are first told [del]how certain[/del] [ins]the numbers in[/ins] some special squares, [del]and[/del] are then furnished with a rule, perhaps not applicable all over the table, but which will extend our knowledge through certain [del]lines[/del] of squares, not necessarily either horizontal rows or [ins]vertical[/ins] columns, but perhaps diagonal or other lines, and [del]are[/del] [ins]if we[/ins] finally given a rule applicable everywhere which will extend our knowledge from those lines over the whole table, we have an implicit knowledge of the function.
