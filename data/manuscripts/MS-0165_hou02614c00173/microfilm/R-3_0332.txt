[u]Theorem 12[/u]. [u]The addition of zero to a number does not alter the number[/u].

[u]Demonstration[/u]. Suppose this to be true [del]of[/del] of any number, N, so that
$0 + N = N$. Then, letting $N'$ denote the number next higher than N, by
Axiom 6, $0 + N' = N'$. Thus, the proposition if true for any number is true
for the next higher.

But, by axiom 7, it is true for $N = 0$. Hence, by Theorem 4, it is
true of every number after 0 in the sequence of numbers. But by defini-
tion 30, all other numbers come after 0 in the sequence. Hence, it is
true of all numbers.

[u]Axiom 8[/u]. 1 is the number next higher than 0.
