[u]Numerical Equations[/u].

An interesting though not very expeditious
way of getting all the roots when their moduli
are all different is the following:-
Writing the equation $x^n + a x^{n-1} + b x^{n-2} + \text{etc.}$
the root of longest modulus is obtained from
the approximate values of all the others by
the equation $-a = \sum_i x_i$.
The next root in order of magnitude
of modulus, by the equation $b = \sum_i \sum_j x_i x_j$,
etc. It is not necessary to begin with [ins]close[/ins]
approximations.

Example. $x^3 - 6x^2 + 10x - 4 = 0$

| [u]$1^{\text{st}}$ Root[/u] | [u]$2^{\text{nd}}$ Root[/u] | [u]$3^{\text{rd}}$ Root[/u] |
| :--- | :--- | :--- |
| $p = 6 - q - r$ | $q = \frac{10 - pr}{p + r}$ | $r = \frac{4}{pq}$ |
| | Assume $0$ | Assume $0$ |
| $6$ | $1.67$ | $0.4$ |
| $3.93$ | $1.95$ | $0.522$ |
| $3.53$ | $2.01$ | $0.563$ |
| $3.43$ | $2.02$ | $0.577$ |
| $3.40$ | $2.02$ | $0.582$ |
| $3.40$ | | |

No matter what the assumed values may be,
the roots will always arrange themselves in this.
