VI. If from an unenclosed oval nothing protrudes but
lines each joined to an index, then, were the oval removed,
its present contents would in the resulting graph be
transformable into any graph at pleasure. (That is,
[ins]would be false[/ins])

VII. [del]If[/del] [ins]In[/ins] a conceivable graph consisting of two graphs,
P and Q, joined, if at all, only by lines each attached to
an index contained in Q, if [del]any[/del] P could be transformed
into any graph at pleasure, then Q, were it written, could
be attached an oval containing P with the same attach-
ments as [del]to[/del] [ins]be[/ins] in that conceivable graph.

You will see that according to these rules

[fig]Oval containing letter A[/fig]

means that A is not true

[pn]AB[/pn]

that A and B are true

[fig]Oval containing letter A and another oval containing letter B[/fig]

That either A or B is true.

[fig]Oval containing letter A and another oval containing letter B[/fig]

That if A is true B is true. So much for the [u]conditional prop.[/u]
