Fourthly One letter added to another, stands all things denoted
by the first together with all the things denoted by the second
besides; and implies that there are [del]not[/del] [ins]no[/ins] things which belong
to both classes at once. Thus m+w stands for all men
together with all women. d + (1-d) stands for all things dead
and all things not dead. dm + (1-d)w stands for all dead
men and all women not dead. [ins]or as we often write it [fig]1/1[/fig][/ins] Fifthly 1, stands for
all that [u]is[/u]; and consequently [fig]1/1[/fig]m stands for all the
men there are, that is for all men; the same as m.
Sixthly 0 or as we often write it [fig]0/1[/fig] stands for what is [u]not[/u],
or nothing, hence [fig]0/1[/fig]m stands for no men, and is the
same as [fig]0/1[/fig] alone. Seventhly [fig]0/0[/fig] stands for some class
we know not what, perhaps for all things, perhaps for nothing
perhaps for some things. Accordingly [fig]0/0[/fig]m stands for [u]some all[/u]
[u]or no[/u] men. [fig]0/0[/fig]w for some all or no women and so forth.
