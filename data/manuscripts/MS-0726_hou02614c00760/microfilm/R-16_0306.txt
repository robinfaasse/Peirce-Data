[pn]1[/pn] All I is C
Some D is not C
$\therefore$ Some D is not I

As All I is C, I equals C which is I. As some D is not C, some D is not C which is I. Hence we have
All C which is I is I
Some D is not C which is I
$\therefore$ Some D is not I.
