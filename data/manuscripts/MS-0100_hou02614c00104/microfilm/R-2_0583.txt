[u]Postulate 2.[/u] Given any three positions $A$ $B$ $C$ (and
$B$ & $C$ may be identical) then [del]let[/del] is it possible
to place a fourth $D$ so that the relation of $A$ to $B$
is the same as that of $C$ to $D$.

[u]Definition of Position[/u]. All real relations of things
consist in the fact that being in one position
they will be in another. Position being wholly re-
lative.

Position has two elements logically extensive
& logically intensive. One a numerical ratio
the other difference in kind.

The numerical ratio is distance. The other
direction.

If $OA : OB = OC : OD$ then this holds in regard
both to distances & direction.

Ratios of distance are always positive numbers.

$b^2 = a(a+d)$  $c^2 = d(a+d)$
$a : b = b : a+d$
$d : c = c : a+d$

$(OX)(X\Xi) = OP$

$OX' = Y'P$  $OY'' = Y''Q$
[fig]Fraction diagram with a, b, c, d[/fig]

[fig]Geometric diagram with axes OX, OY, and points P, Q, P', Q'[/fig]

Any two points $OX$ being taken, take $\Xi$ so that
$\Xi O = OX$

Take $Y$ so that
$OX : OY = OY : O\Xi$

Suppose $x$ and $y$ to be two numbers such that $X'$ and $Y'$
being such that
$x OX = OX'$
$y OY = OY'$
and $P$ being such that
$Y'P = OX'$
we have $\text{Dist } OP = \text{Dist } OX$.

Take $Q$ so that
[del]$OX : OY = OY : Q$[/del]
$OY'' = x OY$  $OX'' = y O\Xi$
$X''Q = OY''$
Then $OX' : OY' = OY'' : OX''$
and $OP : OQ = OX : OY$
[del]$Y'P : OY' = Y''Q : OX''$[/del]
$OX' : Y'P = OY'' : Y''Q$

Then taking $P'$ and $Q'$
$\text{Dist } OP' = y OP$
$OQ' = x OQ$
$\text{Dist } OQ' = \text{Dist } OY''$
$\text{Dist } OQ = \text{Dist } OY$
$\text{Direc } QQ' \text{ \& Direc } OY$
$= \text{Direc } OQ' : \text{Direc } OY''$

Hence
$YOQ' : QOY'' = QOY'' : YOQ'$
Hence ratios of distances being
positive numbers
$\text{Dist } Q'Y = \text{Dist } Y''Q$
$\text{Direc } Q'Y = \text{Direc } Y''O$
$= \text{Direc } YOY$

etc. etc.
$Q'Y = OP'$
Hence $x^2 + y^2 = 1$
