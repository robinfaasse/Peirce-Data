[u]Syllogism[/u]

Indeed, we may go further, and say (as I have done [u]On the[/u]
[u]Classification of Arguments[/u], [date]1867[/date] [del]Apr[/del] p 9) that if we regard
any statement of an argument which reaches the same con-
clusion from the same premises by a greater number of
steps as an [u]analysis[/u] of that argument, then every necessary
inference whatever is syllogistic. Thus:

All A is B
All A is A
$\therefore$ By Darapti Some A is B

No A is B
All B is B
$\therefore$ By Cesare No B is A

All S is P
All T is Q
$\therefore$ All S that is T is P and Q
