If there is a question of cause, of what kind is that cause?

Some defenders seem to think it an efficient cause. If that
is so, the soul would be conceived as an automaton, any
automaton which does external work will run down; but
supposing psychical efficiency to follow the same laws as
physical efficiency, if the soul does no external work, which
we must conceive as psychical work, it would not run
down. But then the soul [ins]in fact[/ins] does [del]internal[/del] psychical work,
whether it does physical work or not; and whether psy-
chical work does or does not exhaust a psychical agent,
we simply do not know. [del]Probably[/del] [ins]But[/ins] the argument
amounts to nothing. If a formal cause is intended, the
argument would be better; but it would seem [del]to be[/del], so un-
derstood, to be little more than an inappropriate way
