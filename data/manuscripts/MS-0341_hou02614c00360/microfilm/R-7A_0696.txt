There is a large class of reasonings which are neither [del]demonstrative[/del] [ins]deductive[/ins]
nor inductive. I mean the inference of a cause from its effect
or reasoning to a physical hypothesis [del]or universal law[/del]. I call this
reasoning <u>à posteriori</u>. If I reason that certain conduct is wise
because it has a character which belongs only to wise things, I
reason <u>à priori</u>. If I think it is wise because it once turned out
to be wise, that is if I infer that it is wise on this occasion because
it was wise on that occasion, I reason inductively. But if I think it is
wise because [ins]a[/ins] wise man does it, & then make the [ins]being[/ins] hypothesis that
he does it because he is wise, and I reason <u>à posteriori</u>. The form
this reasoning assumes, is that of an inference of a minor premiss
in any of the figures. The following is an example

[fig]vertical line dividing two syllogistic arguments[/fig]

Light gives certain fringes
Ether waves give these fringes
$\therefore$ Light is ether waves

Ether waves give certain fringes
Light is ether waves
$\therefore$ Light gives these fringes.
