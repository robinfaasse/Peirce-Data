It does not follow [del]that[/del] because A is transformable
into B, that A-C is transformable in B-C. For
if there is a cockatrice's egg, there is a female cockatrice,
but it does not follow that if some cockatrice's egg is
speckled, therefore some female cockatrice is speckled.
