[u]Corollary 5.[/u] Any graph, A, is scriptible, if and only if,
a graph [del]consist[/del] [ins]consisting[/ins] [ins]of[/ins] the same graph enclosed
in two ovals containing nothing else is scriptible.

For if A is not scriptible it is transformable into any
graph whatever, since the transformation will not change
a scriptible into an unscriptible graph. Consequently, [ins]A[/ins]
will be scriptible. Now [ins]A[/ins] being scriptible is not trans-
formable into A, which is not scriptible. Consequently,
[ins]A[/ins] is not transformable into any graph that may be
proposed. Hence [ins]A[/ins] will be unscriptible like A.

But if A is scriptible, and there is no unscriptible
graph, [ins]A[/ins] is scriptible, like A. But if there is any un-
scriptible graph, A, being scriptible is not transformable into
any graph whatever, and therefore [ins]A[/ins] will be unscriptible.
Since [ins]A[/ins] is unscriptible, [del][ins]A[/ins][/del] it will be transformable into
any graph whatever without transforming a scriptible into
an unscriptible graph; and therefore again [ins]A[/ins] will be scriptible.
