Corollary 5. Any graph, A, is scriptible, if and only if, a graph [del]consists[/del] [ins][fig]((A))[/fig][/ins] consisting of the same graph enclosed in two ovals containing nothing else is scriptible.

For if A is not scriptible it is transformable into any graph whatever, since the transformation will not change a scriptible into an unscriptible graph. Consequently, [fig]((A))[/fig] will be scriptible. Now [fig]((A))[/fig] being scriptible is not transformable into A, which is not scriptible. Consequently, [fig]((A))[/fig] is not transformable into any graph that may be proposed. Hence [fig]((A))[/fig] will be unscriptible like A.

But if A is scriptible, and there is no unscriptible graph, [fig]((A))[/fig] is scriptible, like A. But if there is any unscriptible graph, A, being scriptible is not transformable into any graph whatever, and therefore [fig]((A))[/fig] will be unscriptible. Since [fig]((A))[/fig] is unscriptible, [del][fig]((A))[/fig][/del], it will be transformable into any graph whatever without transforming a scriptible into an unscriptible graph; and therefore again [fig]((A))[/fig] will be scriptible.
