29 [ured]Corollary 11.[/ured] If a graph is scriptible, consisting of an oval enclosing two graphs, then either of these, if written as an entire graph, would be transformable into an oval enclosure containing only the other.

For if [fig](AB)[/fig] is scriptible, then AB is transformable into any graph, C. That is, under any circumstances under which A and B are both scriptible, C is scriptible. If then, either of these is scriptible, the other [ins]as an entire graph,[/ins] when scriptible [del]as an entire graph,[/del] would be transformable into C. Now since C may be any graph whatever, if A is scriptible [fig](B)[/fig] must be scriptible. That is, the transformation of A into [fig](B)[/fig] cannot be a transformation of the scriptible into the non-scriptible.

[ured]Theorem II.[/ured] If a graph, A, is not transformable into a graph, B, there must be some scriptible graph, M, which is transformable into A and also into [fig](B)[/fig].
