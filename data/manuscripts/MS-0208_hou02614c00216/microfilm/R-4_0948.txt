[u]Propositions in the Arithmetic of Two.[/u]

1. When $M = \text{GGO}$, $\text{R}_{\text{GGO}} N = \text{O}$ or $\text{R}_{\text{GGO}} N = \text{GO}$.

2. If $\text{R}_{\text{GGO}} N = \text{O}$ $\text{R}_{\text{GGO}} \text{G} N = \text{GO}$ because $\text{G} N = \text{GO} + N$ and $\text{R}_{\text{GGO}} \text{GO} = \text{GO}$.

3. If $\text{R}_{\text{GGO}} N = \text{GO}$ $\text{R}_{\text{GGO}} \text{G} N = \text{O}$. For then
$$N = \text{GO} + (\text{Q}_{\text{GGO}} N) \cdot \text{GGO}$$
$$\text{G} N = \text{G} [\text{GO} + (\text{Q}_{\text{GGO}} N) \cdot \text{GGO}] = \text{GGO} + (\text{Q}_{\text{GGO}} N) \cdot \text{GGO} = (\text{G} \text{Q}_{\text{GGO}} N) \cdot \text{GGO}.$$

4. Either $\text{R}_{\text{GGO}} N = \text{O}$ or $\text{R}_{\text{GGO}} \text{G} N = \text{O}$ but not both.

5. $\text{GGO} \times N = N + N$. For $\text{GGO} \times N = [del]N[/del] [ins]\text{O}[/ins] + \text{GO} \cdot N = N + N$.
