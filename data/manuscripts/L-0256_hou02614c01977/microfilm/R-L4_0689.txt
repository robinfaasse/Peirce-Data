It is subject to two Rules. The first is that a
sample is fairly representative of a class only if
it has been drawn from that class by a method
which would in the long run give every unit
of the class an equal chance of being drawn;

and consequently, the inductive conclusion ought not to refer to the
class from which it has been drawn, but to a class of which the sample
is fairly representative. For instance, if one has only taken those units
that struck the eye, one should confine one's induction to the more pro-
minent units of the class. [u]The second rule is that the purpose for which[/u]
[u]the sample is to be used ought to be designated beforehand (or virtually, at[/u]
[u]least) and the sample should be made [del]for[/del] as far as possible for that[/u]
[u]purpose.[/u] The reason is that every sample has its peculiarities which
can be found by sufficient study after it has been drawn, but which
would, no one of such peculiarities be likely to belong to any single sample
fairly drawn. If one knows beforehand what one is to use the sample
for one can be on one's guard to render it fair in that respect; and unless
the reasoner makes an earnest and honest effort to be fair his Induction
will deceive those who rely upon it.
