To say that two propositions P and Q are logically equivalent is the same as to say that if P is true Q is true and if Q is true P is true. Now no matter what consequent X may be, it is always true that if any proposition T is true, it is also true that if it be true that X follows necessarily if T is true then X is true. For example, let T be "you murder," and X "you sin." If it be true that you murder then it follows that it is true that if murder is a sin, [ins]then[/ins] you sin. But the converse is not true for every consequent. That is, it is not generally true, that because if murder is a sin then you sin, that you murder. You may have done something which on the principle that murder is a sin must be accounted a sin. But it need not be murder.
