$$w = xy$$
$$S = x\bar{y} + \bar{x}y$$

Consolidating these into one proposition by the methods under Consolidation we have:
$$\bar{w}xy + w(1-xy) + \bar{S}(x\bar{y} + \bar{x}y) + S(xy + \bar{x}\bar{y}) = 0$$

From this we obtain the value of $w$ as follows:
$$w = \frac{\bar{S}x\bar{y} + S\bar{x}y + Sxy + \bar{S}\bar{x}\bar{y}}{2xy - 1}$$

We need to develop the above equation in terms of $S, x$ and $y$.

The easiest way to do this is to write the class terms in the scheme of the Possible in a vertical column to the left and to write the class terms in the function to be developed along the head of the column. Multiply these together leaving blanks where the product is zero.

The result will be as follows:
