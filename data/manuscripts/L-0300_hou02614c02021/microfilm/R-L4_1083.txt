I think the penalty for your failing to complete the report should be the exact cost on January 1, 1902 or $1426.80. If then you were to make a note for $3000 due January 1, 1902 this note would provide for the following amounts.

| | |
|---|---|
| Penalty for report | $1426.80 |
| Stickney advances and interest | 471.76 |
| Notes and interest | 187.17 |
| Balance | [u]914.27[/u] |
| | $3000.00 |

The balance $914.27 discounted for three years would be equivalent to $749.70 January 1st, 1899. Such an arrangement as this I am ready to consider, but before finally deciding there are some details which I think should be fully understood.

The note should be for the full $3000 with the usual collateral clauses and should contain no reference to the penalty provision. I would give you a letter in which I should agree to credit the amount mentioned above on the principal when the report is delivered to me; or in the event of the note having been paid off to refund to you that amount.
