[u]Definition[/u]. An [u]associative operation[/u] is [del]such as opera-[/del] [del]tion[/del] a mode of combining a first and a second object, which may be called [u]agent[/u] and [u]patient[/u] respectively, that if the result is made agent to any third object as patient, the final result is the same as if the [del]first[/del] [ins]second[/ins] object were [ins]first[/ins] made agent to the third as patient and the result were made patient to the first as agent.

[u]Illustration[/u]. Thus if we line a bag (considered as agent) with another bag (considered as patient) so that the combination is a bag, the effect is the same whether we [ins]insert[/ins] make a third bag as lining to the doubled bag, or whether we begin by lining the second with the third and then line the first with this double bag. Such a lining operation, then, is an associative operation.
