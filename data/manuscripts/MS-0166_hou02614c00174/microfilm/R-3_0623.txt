[u]Axiom 6[/u]. The effect of substituting for either term of a sum [del]the number[/del] [ins]which is a[/ins] whole number the number next higher is to make the sum the number next higher.

[u]Axiom 7[/u]. 0 + 0 = 0.

[u]Theorem 10[/u]. [u]The sum of two whole numbers is a whole number[/u].

[u]Demonstration[/u]. For if this is true for any two numbers, it is true, when either of them is the number next higher, by Axiom 6.

But, by Axiom 7, it is true when both are 0. Hence, it is true for all whole numbers.

[u]Theorem 11[/u]. [u]Addition is a commutative mode of combination[/u].

[u]Demonstration[/u]. Let X and Y be any two [ins]unequal[/ins] [del]whole[/del] numbers, of which X is greater than Y. Then I say X + Y = Y + X.

For suppose this is true when X [del]being greater than[/del] [ins]had a certain value[/ins] N greater than Y, [del]and so[/del] that N + Y = Y + N and let N' be the number next greater than N. Then by axiom 6, N' + Y is next greater than N + Y and Y + N' is next greater than Y + N. Hence N' + Y = Y + N'. [del]Hence[/del] [ins]Thus,[/ins] if the proposition is true for any number [del]not smaller than Y[/del] it is true for the [del]next[/del] [ins]greater[/ins]. But it is true when N = Y. For Y + Y = Y + Y. Hence, it is true for all numbers as great (or greater) than Y.
