[u]Definition 21.[/u] A sequence [ins]is said to[/ins] [u]advance[/u] [del]by steps[/del], if every object in it, except the last, has another next after it.

A sequence is [u]proclive[/u] at an object in it not the last, if there is no object next after that object.

A sequence is [u]reclive[/u] at an object in it not the first, if that object does not come next after any other.
