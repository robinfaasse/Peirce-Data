[u]Rule for addition[/u].

1. Set down the numbers under one another, [del]all[/del] figures in the same place of decimals in the same vertical column.

2. Draw a line under the numbers, leaving room to set down figures above it.

3. Add all the [del]figures[/del] [ins]numbers[/ins] above the line in the right hand [del]place of decimal place, and set down[/del] [ins]column[/ins] [del]each figure in the column and set down to its decimal place[/del] the sum above the line, except only the last figure which place below the line. [ins][See Rule for adding a column below.][/ins]

4. [del]Proceed[/del] [ins]Add[/ins] in the same way [del]successively with[/del] the [del]right hand column[/del] [ins]and so proceed[/ins] [del]not yet added, the furthest to the right, until there remain[/del] [ins]until there remain[/ins] no more columns [del]remain[/del] to be added.
