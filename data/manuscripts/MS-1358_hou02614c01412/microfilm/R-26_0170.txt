\(x_n = \text{Const} + \frac{S}{2} \cos (\theta + \vartheta)_n\) \(y_n = \text{const} + \frac{S}{2} \sin (\theta + \vartheta)_n\)

\(x_{n+ds} = \text{Const} + S [ \cos (\theta + \vartheta)_n + \frac{1}{2} \cos (\theta + \vartheta)_{n+ds} ]\) \(y_{n+ds} = \text{Const} + S [ \sin (\theta + \vartheta)_n + \frac{1}{2} \sin (\theta + \vartheta)_{n+ds} ]\)

\(\delta x_n = - \frac{S}{2} \sin (\theta + \vartheta)_n \delta \theta_n\) \(\delta y_n = + \frac{S}{2} \cos (\theta + \vartheta)_n \delta \theta_n\)

\(\delta x_{n+ds} = - S [ \sin (\theta + \vartheta)_n \delta \theta_n + \frac{1}{2} \sin (\theta + \vartheta)_{n+ds} \delta \theta_{n+ds} ]\) \(\delta y_{n+ds} = S [ \cos (\theta + \vartheta)_n \delta \theta_n + \frac{1}{2} \cos (\theta + \vartheta)_{n+ds} \delta \theta_{n+ds} ]\)

\(\delta x_{n+\frac{3}{2}ds} = - S [ \sin (\theta + \vartheta)_n \delta \theta_n + \sin (\theta + \vartheta)_{n+ds} \delta \theta_{n+ds} ]\)

\(\begin{aligned} 0 &= \cos (\theta + \vartheta)_n \delta \theta_n + \cos (\theta + \vartheta)_{n+ds} \delta \theta_{n+ds} \\ \delta \theta_{n+ds} &= - \delta \theta_n \frac{\cos (\theta + \vartheta)_n}{\cos (\theta + \vartheta)_{n+ds}} \end{aligned}\)

\(\begin{aligned} &= S [ \frac{\sin (\theta + \vartheta)_{n+ds} - (\theta + \vartheta)_n}{\cos (\theta + \vartheta)_{n+ds}} ] \delta \theta_n \end{aligned}\)

\(\delta x_{n+ds} = S [ \frac{1}{2} \tan (\theta + \vartheta)_{n+ds} \cos (\theta + \vartheta)_n - \sin (\theta + \vartheta)_n ] \delta \theta_n\)
