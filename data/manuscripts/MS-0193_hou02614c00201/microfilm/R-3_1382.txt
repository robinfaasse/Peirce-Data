$\sin x$ is a function of $x$ having the following
properties:

$1^{\text{st}}$, [del]If[/del] [ins]$\sin x$[/ins] [del]has[/del] [ins]is a single[/ins] [del]a[/del] definite value for each value of $x$.
$2^{\text{d}}$, It has a single definite differential coefficient for
each value of $x$. That is to say, if $x = u + v i$ where
$u$ and $v$ are real and $i^2 = -1$, the same general
formula for $\sin (c+x)$ applies for all values of $u$
and $v$.

$3^{\text{d}}$, There is a constant quantity $\pi$ such that in
all cases $\sin (x+\pi) = -\sin x$.

$4^{\text{th}}$. $\sin 0 = 0$
$5^{\text{th}}$. $\sin \infty = \infty$
$6^{\text{th}}$. $\sin \frac{1}{2}\pi = 1$
