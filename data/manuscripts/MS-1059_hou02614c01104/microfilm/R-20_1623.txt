$\eta = - \frac{1}{2} \frac{2 a X + (1-a^2) Y + (1+a^2) c + 2 a \bar{c}}{1+a^2}$

$= \frac{\sqrt{X^2 + Y^2 + (1-a^2) c Y + 2 a c X + 2 \bar{c} X}}{1+a^2}$

$= - 2 \frac{X^2 + Y^2 + (1-a^2) c Y + 2 a c X + 2 \bar{c} X}{2 a X + (1-a^2) Y + (1+a^2) c + 2 a \bar{c}}$
