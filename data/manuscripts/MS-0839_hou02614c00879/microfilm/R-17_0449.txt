the same property, it follows that if 0 has that
property every number has it. It might be
doubted whether, in place of [u]some[/u], we ought
not rather to say [u]all[/u], which would modify
the shorthand expression, so as to put, in
place of

The truth is, it is a matter of no consequence; for if
there be a relation which will make either true,
there is a relation which will make the other true.
