§5. [u]Logical Interpretation of the Basic Rules by means of the Constitutive[/u]
[u]Conventions[/u].

I. Some graph cannot be written unenclosed. That is, some
proposition is false.
It is quite possible that a mind incapable of conceiving
falsity should reason. But [del]such[/del] [ins]such[/ins] a mind could have
no logic. It could only accept, not reject.

II. A graph, once written, may remain. That is, that which is
once true is always true.
For the flow of time concerns only our state of knowledge;
but the truth is independent of our state of knowledge. This
is anti-Hegelian.

III. The graph may be erased. That is, there is no falsity in non-
assertion. Another anti-Hegelian position.

IV Graphs that can be separately written can be written together.
That is, propositions that are each true are true when
combined.

V. Every rule of illative [del]transformation[/del] [ins]insertion or erasure[/ins] applies to every
unenclosed graph. For instance, if it is a rule that
if A can be transformed into AB, then C can be transformed
into CD, it is equally a rule that if AE can be transformed
into ABE, then CE can be transformed into CDE.
For every rule permits certain transformations under
all circumstances when certain conditions are fulfilled.
Therefore when [del]other[/del] [ins]certain[/ins] circumstances are true in addition to those
conditions the rule permits the same transformations.
