[u]6th[/u], a [u]Rhematic Indexical Legisign[/u] is any general type or law,
however established, which requires any instance of it to be really
connected with some object in such a way as to call attention
to that object. The special instance of it is a [u]Rhematic Indexical
Segin[/u].

[u]7th[/u], a [u]Dicent Indexical Legisign[/u] is any general type or law,
however established, which requires any instance of it to be
really so connected with some object in such a way as to furnish
definite information concerning that object. It may be regarded
as a quasi-composite of a [u]Rhematic Indexical Legisign[/u] and
an [u]Iconic Legisign[/u], and any special instance of it is a [u]Dicent
Indexical Segin[/u].
