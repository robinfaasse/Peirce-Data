My dear Professor Moore:

With wishes for your merry christmas and a prosperous new year, I send an addition to my last letter.

The principle that if of a class of propositions each one is possible under every possible determination of the others as to truth-falsity, then all are simultaneously possible, is a corollary from the definitions of possibility and simultaneity.

But I will describe a collection of Xs which does not stand in the relation r to any Y. In order to do this I divide the Xs into three classes.

Class I comprises all the Xs (if any) to which no collection of Xs stands in the relation r, together with all to which several (more than one) collections of Xs stand in the relation r.

Class II comprises all the Ys [ins]each of[/ins] to which a single collection containing this X stands in the relation r.

Class III comprises all the Xs each of which a single collection not containing X stands in the relation r.

Now my test collection of Xs shall include all the Xs (if any) of Class III and shall exclude all the Xs (if any) of Class II. As to Class I, I do not care whether they are included or not. This test collection I say is not in the relation r to any Y to which no other collection of Xs is in the relation r. It is not so related to any Y of Class III because it includes all of this class, while the sole collection of Xs that is in the relation r to any one of this class excludes that one.
