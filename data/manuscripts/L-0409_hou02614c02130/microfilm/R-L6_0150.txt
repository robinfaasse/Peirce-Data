The validity of pure induction is not that it renders
the conclusion probable. It could not do that unless we
knew an antecedent value of that probability; and if we
reason in that way, the argument is so far not inductive
but is simply a mathematical, and therefore necessary,
argument concerning probabilities. But although,
induction does not render the conclusion probable, yet
it can be mathematically demonstrated that it is probable
that an induction of a given type will, if certain conditions
are fulfilled, be approximately true. There is a great difference
between these two things, because we do not know how
we should be able to make an induction of that type.
If we knew that, from the probability of such a kind of induction
being true we could infer the probability of the conclusion.
