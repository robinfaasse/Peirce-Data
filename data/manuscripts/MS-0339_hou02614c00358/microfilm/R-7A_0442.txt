[del]The first division of signs is into[/del]
[del]An Icon is a sign which refers to the Object that it[/del]
[del]denotes merely by virtue of characters of its own, and[/del]
[del]which it possesses, just as much whether such[/del]
[del]Object actually exists or not. An Index is a sign[/del]
[del]which refers to the Object that it denotes by virtue of[/del]
[del]being really affected by that Object. A Symbol is a[/del]
[del]sign which refers to the Object that it denotes by virtue[/del]
[del]of a law, usually an association of general ideas, which[/del]
[del]operates to cause the Symbol to be interpreted as[/del]
[del]referring to that Object.[/del]
[del]The Index is physically connected with its object;[/del]
[del]they make an organic pair. But the interpreting mind[/del]
[del]has nothing to do with this connection, except to[/del]
[del]remark it, after it is established. The Symbol is[/del]
[del]connected with its object by virtue of the idea of the[/del]
[del]symbol-using mind, without which no such connection[/del]
[del]would exist. The Icon has no dynamical connection[/del]
[del]with the object it represents; it simply happens that[/del]
[del]its qualities resemble those of that object, and excite[/del]
[del]analogous sensations in the mind for which it is a[/del]
[del]likeness. But it really stands unconnected with them.[/del]
[del]The Index asserts nothing; it only says "There!"[/del]
[del]It grabs us, as it were, by the eyes and forces[/del]
[del]them to look at a particular object, and there it[/del]
[del]stops. It is a physical force. It is a compulsion.[/del]
[del]The Icon, also, asserts nothing. It is a mere[/del]
[del]image. It is a possibility. It is a dream.[/del]
[del]The Symbol, on the other hand, is a law, or[/del]
[del]regularity of the indefinite future. Its value consists[/del]
[del]in its being a rule which will determine our[/del]
[del]conduct. It is a general. But a general cannot[/del]
[del]exist. It can only be in the future, as a law.[/del]
[del]But a law cannot be unless it is manifested in[/del]
[del]instances. These instances are indices. They are[/del]
[del]what so have singulars. Otherwise [del]they[/del] [ins]it[/ins][/del]
[del]could not be distinguished.[/del]
[del]An Icon is a sign which would possess the character[/del]
[del]which renders it significant, even though its[/del]
[del]object had no existence; such as a lead-pencil streak[/del]
[del]as representing a geometrical line. An Index is a sign[/del]
[del]which would, at once, lose the character which makes[/del]
[del]it a sign if its object were removed, but would not[/del]
[del]lose that character if there were no interpretant.[/del]
[del]Such, for instance, is a piece of mould with a[/del]
[del]bullet-hole in it as sign of a shot; for without[/del]
[del]the shot there would have been no hole; but[/del]
[del]there is a hole there, whether anybody has[/del]

[del]A Symbol is a sign which would lose the character[/del]
[del]which renders it a sign if there were no interpretant.[/del]
