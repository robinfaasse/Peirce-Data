Two kinds of disquiparants

1[sup]st[/sup] those which would be of the same internal character as they are, even without reference to the correlate as [u]greater[/u]

2[sup]nd[/sup] such whose internal character is affected by the reference to a correlate as [u]killed[/u]

This division seems to correspond to that of symbols into [u]terms[/u], [u]propositions[/u], [u]arguments[/u].

For a [u]term[/u] would have the same character even if its object should be destroyed

A [u]proposition[/u] would remain the same even if its interpretant should cease. Though not if its object were destroyed

An [u]argument[/u] could not be the same if either object or interpretant were destroyed.
