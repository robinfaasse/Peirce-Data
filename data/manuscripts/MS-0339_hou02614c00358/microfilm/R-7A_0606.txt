Suppose Two elastic oscillations

A force of restitution upon each oscillating
body, equal to $D_t^2 s_1 = - g_1 s_1$ [del]$D_t^2 s_2 = - g_2 s_2$[/del]
A force of one upon the other [del]$D_t^2 s_1 = a (s_2 - s_1)$[/del]
[del]$D_t^2 (s_1 - s_2) = a (s_2 - s_1)$[/del] [del]$D_t^2 s_2 = a (s_1 - s_2)$[/del]

So that
$D_t^2 s_1 = - (a + g_1) s_1 + a s_2$
$D_t^2 s_2 = a s_1 - (a + g_2) s_2$

Then suppose [del]$x$[/del] [ins]and $y$[/ins] to be such that
[del]$D_t^2 [x s_1 + (1-x) s_2] = - y [x s_1 + (1-x) s_2]$[/del]
[del]$= - x (a + g_1) s_1 + x a s_2$[/del]
[del]$+ (1-x) a s_1 - (1-x) (a + g_2) s_2$[/del]
[del]$= [a - (2a + g_1) x] s_1 - [a - (2a + g_2) x] s_2$[/del]

[marginalia]
$\frac{p}{p+q} + \frac{q}{p+q}$

$+ q a s_1 - q (a + g_2) s_2$
