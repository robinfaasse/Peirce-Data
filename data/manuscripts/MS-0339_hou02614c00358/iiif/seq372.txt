The algebra of the copula is deducible from the definition of the copula. This definition positively asserts that some things can be written.

First says if [u]q[/u] then [u]p[/u] ≺ [u]q[/u]
             Either [u]p[/u] or [u]p[/u] ≺ [u]q[/u]
For [del][u]q[/u][/del] put [u]p[/u], then this becomes if [u]p[/u] then [u]p[/u] ≺ [u]p[/u]
                                             Either [u]p[/u] or [u]p[/u] ≺ [u]p[/u]
Therefore [u]p[/u] ≺ [u]p[/u] is positively asserted to be permissible scriptible
But the definition of the copula does not positively [ins]say[/ins] that [del]anything can be written[/del] there is anything that cannot be written.
It only distinguishes between what we know to be scriptible and what we do not know to be scriptible

The definition seems to be
(1) If [u]q[/u], then [u]p[/u] ≺ [u]q[/u]
(2) Either [u]p[/u] or [u]p[/u] ≺ [u]q[/u]
(3) If [u]p[/u] and [u]p[/u] ≺ [u]q[/u], then [u]q[/u]
