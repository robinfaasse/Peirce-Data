Try to define a pair, an ordered pair. You are
driven to the idea of a sign. An ordered pair, or
couple, is an object of which whatever is true is [del]true[/del]
[ins]ipso facto[/ins] true of a first object in one sense and
of a second object in another sense. Or an ordered
pair is an object in respect to which one object
corresponds to another.

An ordered pair is an object whose essence
consists in one existing object being taken as first
and another as second.

the first in a certain ordered pair [del]of[/del] which the
