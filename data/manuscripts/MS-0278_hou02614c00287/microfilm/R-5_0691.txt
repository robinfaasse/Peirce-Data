$$\tan A = \frac{\tan a}{\sin b}$$
$$\tan^2 A = \frac{\tan^2 a}{\sin^2 b}$$
$$\sec^2 A = \frac{\sin^2 b + \tan^2 a}{\sin^2 b}$$
$$\cos^2 A = \frac{\sin^2 b}{\sin^2 b + \tan^2 a}$$
$$\sin^2 A = \frac{\tan^2 a}{\sin^2 b + \tan^2 a}$$

$$A = \alpha + 45^\circ$$
$$\tan (\alpha + 45^\circ) = \sec 2\alpha + \tan 2\alpha$$

$$\cos c = \cos a \cos b$$
$$\cos^2 c = \cos^2 a \cos^2 b$$
$$\sec^2 c = \sec^2 a \sec^2 b$$
$$\tan^2 c = \sec^2 a \sec^2 b - 1$$

$$\sin^2 A = \frac{\tan^2 a}{\sin^2 b + \tan^2 a} = \frac{\tan^2 a}{1 + \frac{\tan^2 a}{\sin^2 b}}$$

$$\tan b' = \cos \sin A \tan c = \sin A \sqrt{\sec^2 a \sec^2 b - 1}$$
$$\sin a' = \cos A \sin c$$
$$\tan a' = \frac{\cos A \sin c}{\sqrt{1 - \cos^2 A \sin^2 c}}$$
$$= \frac{\tan a}{\sqrt{\sin^2 b + \tan^2 a}}$$

$$\sin^2 x = 1 - \cos^2 x$$
$$\tan^2 x = \frac{\sin^2 x}{1 - \sin^2 x} = \frac{1}{\frac{1}{\tan^2 x} + 1}$$
$$\tan^2 - \tan^2 \sin^2 = \sin^2$$
$$\tan^2 = \sin^2 (1 + \tan^2)$$
$$\sin = \frac{\tan}{\sqrt{1 + \tan^2}}$$

$$\frac{\tan^2 a + 1}{\tan^2 b + 1}$$
$$\tan^2 a \tan^2 b + \tan^2 a + \tan^2 b$$

$$\tan A = \frac{\tan a}{\tan b} \sqrt{1 + \tan^2 b}$$

$$\tan b' = \frac{\tan A}{\sqrt{1 + \tan^2 A}} \sqrt{\tan^2 a \tan^2 b + \tan^2 a + \tan^2 b}$$
$$= \frac{\frac{\tan a}{\tan b} \sqrt{1 + \tan^2 b}}{\sqrt{1 + \frac{\tan^2 a}{\tan^2 b} (1 + \tan^2 b)}} \sqrt{\tan^2 a \tan^2 b + \tan^2 a + \tan^2 b}$$
$$\tan b' = \frac{\tan a \sqrt{1 + \tan^2 b}}{\sqrt{\tan^2 b + \tan^2 a + \tan^2 a \tan^2 b}}$$

$$\tan^2 = \frac{1}{\frac{1}{\tan^2} + 1} = \frac{1}{1 - \sin^2}$$
$$1 - \sin^2 = \frac{1}{\tan^2 + 1}$$
$$\sin^2 = \frac{\tan^2}{\tan^2 + 1}$$
