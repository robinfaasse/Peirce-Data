There must then be some value of $x$ for which
$\cos x = \frac{1}{4} (\sqrt{6} + \sqrt{2})$. Then
$\cos^{2} x = \frac{1}{16} (8 + 2\sqrt{12}) = \frac{1}{4} (2 + \sqrt{3})$
$1 - \cos^{2} x = \frac{1}{4} (2 - \sqrt{3}) = \frac{1}{16} (8 - 2\sqrt{12})$
$\sin x = \frac{1}{4} (\sqrt{6} - \sqrt{2})$
Call this value of $x$ [u]one hour[/u]. Denote it by [u]$h$[/u].
$\sin h = \frac{1}{4} (\sqrt{6} - \sqrt{2})$     $\cos h = \frac{1}{4} (\sqrt{6} + \sqrt{2})$
$\sin 2h = \frac{2}{16} (6 - 2) = \frac{1}{2}$     $\cos 2h = \frac{\sqrt{3}}{2}$
$\sin 3h = \sin (2h + h) = \frac{1}{8} (\sqrt{6} + \sqrt{2}) + \frac{\sqrt{3}}{8} (\sqrt{6} - \sqrt{2}) = \frac{1}{\sqrt{2}}$
