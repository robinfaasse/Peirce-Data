[u]Theorem 24[/u]. [u]Multiplication of whole numbers is an associative combination[/u].

[u]Demonstration[/u]. Let $L, M, N$ be any three whole numbers. Then $(LM)N = L(MN)$. For suppose this holds good when $M$ is any whole number $P$, then [del]it holds[/del] [ins]it equally[/ins] holds also, if $M$ is the number $P'$ next greater than $P$. For [del]$(LP')N = [L(1 + P)]N = (L + LP)N$[/del] $= LN + (LP)N = LN + L(PN) = L(N + PN) = L[(1 + P)N] = L(P'N)$. Now, it does hold good for $M = 0$, since $(L0)N = 0N = 0 = L0 = L(0N)$. Hence, it holds good for all whole numbers.

[u]Theorem 25[/u]. [ins](The Commutative Principle of Multiplication)[/ins] [u]The multiplication of whole numbers is a commutative operation[/u].

But if $Y = 0$, $XY = X0 = 0 = 0X = YX$. Hence, [del]when[/del] [ins]when $Y$ is any[/ins] whole number $XY = YX$. Q.E.D.
