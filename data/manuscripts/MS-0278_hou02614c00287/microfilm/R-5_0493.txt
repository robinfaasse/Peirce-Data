$$\sin(x+y) = \sin x \cos y + \cos x \sin y$$

$$\sin^{2}(x+y) = \sin^{2}x (1-\sin^{2}y) + (1-\sin^{2}x)\sin^{2}y$$
$$+ 2\sin x \sin y \cos x \cos y$$

$$\sin^{2}(x+y) - \sin^{2}x - \sin^{2}y + 2\sin^{2}x\sin^{2}y = 2\sin x \sin y \cos x \cos y$$

$$\sin^{4}(x+y) + \sin^{4}x + \sin^{4}y [del]+ 4\sin^{4}x\sin^{4}y[/del]$$
$$-2\sin^{2}(x+y)\sin^{2}x - 2\sin^{2}(x+y)\sin^{2}y + 4\sin^{2}(x+y)\sin^{2}x\sin^{2}y$$
$$+ 2\sin^{2}x\sin^{2}y [del]- 4\sin^{4}x\sin^{2}y - 4\sin^{2}x\sin^{4}y[/del]$$
$$= 4\sin^{2}x\sin^{2}y [del]- 4\sin^{4}x\sin^{2}y - 4\sin^{2}x\sin^{4}y + 4\sin^{4}x\sin^{4}y[/del]$$

$$\sin^{4}(x+y) [del]- 2\sin^{2}(x+y)[/del] (\sin^{2}x + \sin^{2}y - 2\sin^{2}x\sin^{2}y) + (\sin^{2}x - \sin^{2}y)^{2} = 0$$

$$+ 2\sin^{2}x\sin^{2}y - 4\sin^{4}x\sin^{2}y - 4\sin^{2}x\sin^{4}y$$
