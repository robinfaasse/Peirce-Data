[u]1[/u] [u]Let us suppose $x$ to be a variable[/u]
[u]which receives an increment $\Delta x$ and[/u]
[u]let $fx$ be a function of the variable. We wish[/u]
[u]to find value of $f(x+\Delta x) = u + \Delta u$. It will be[/u]
[u]if developed according to the integral powers of[/u]
[u]$\Delta x$, $u + \Delta u = fx + P\Delta x + Q\Delta x^2 + R\Delta x^3 + S\Delta x^4$[/u]
[u]where we wish to find values of $P, Q, \&\ S$. Since[/u]
[u]$u = fx$, we have[/u]
[u]$\Delta u = P\Delta x + Q(\Delta x)^2 + R(\Delta x)^3 \&c.$, dividing by[/u]
[u]$\Delta x$, we have[/u]
[u]$\frac{\Delta u}{\Delta x} = P + Q\Delta x + R(\Delta x)^2 + \&c.$ - taking limits[/u]
[u]we obtain $\mathcal{D}_x u = P + Q dx + R dx^2 + \&c. = P$ as $dx$ \&c[/u]
[u]are infinitesimals. Hence $\mathcal{D}_x u = P$.[/u]
[u]Now let us have $x$ for variable and $h$ for[/u]
[u]increment and let the value of $f(x+h)$ when[/u]
[u]expanded be[/u]
[u]$f(x+h) = fx + Ph + Qh^2 + Rh^3 + \&c.$[/u]
[u]here we know $P = \mathcal{D}_x fx$. And by similar[/u]
[u]reasoning it would follow, $Q = \mathcal{D}_x^2 fx, R = \mathcal{D}_x^3 fx \&c.$[/u]
[u]Differentiating [ins]successively[/ins] this form we obtain:[/u]
[u]$\mathcal{D}_x fx = P$, $\mathcal{D}_x^2 fx = 1.2.Q$, $\mathcal{D}_x^3 fx = 1.2.3.R$ \&c. Hence[/u]
[u]by substituting these values we obtain Taylors Theorem[/u]
[u]$f(x+h) = fx + \mathcal{D}_x fx h + \mathcal{D}_x^2 fx \frac{h^2}{1.2} + \mathcal{D}_x^3 fx \frac{h^3}{1.2.3} \&c.$[/u]
