[u]Examples[/u]
$D_x \log [x + \sqrt{1+x^2}] = \frac{1}{\sqrt{1+x^2}}$
$D_x (\log x)^n = \frac{n(\log x)^{n-1}}{x}$
$D_x \log^2 x = \frac{1}{x \log x}$
$D_x \log^3 x = \frac{1}{x \log x \log^2 x}$
$D_x a^{b^x} = \log a . \log b . a^{b^x} . b^x$
$D_x x^y = y x^{y-1} + \log x . x^y D_x y$

[u]Circular Functions[/u]
$d \sin x = \sin (1+d)x - \sin x =$
$\sin x \cos dx + \cos x \sin dx - \sin x =$
[del]$\sin x + dx \cos x$[/del]
$D_x \sin x = \cos x$

[del]$d \cos x = \cos (1+d)x - \cos x =$[/del]
$d \sin (\frac{1}{2}\partial - x) = d(\frac{1}{2}\partial - x) \cos (\frac{1}{2}\partial - x)$
$d \cos x = -dx \sin x$
$D_x \cos x = -\sin x$

$D \sin x = \cos x = D^5$
$D^2 \sin x = -\sin x = D^6$
$D^3 \sin x = -\cos x = D^7$
$D^4 \sin x = \sin x = D^8$

$D \sin 0 = 1$ $D^2 \sin 0 = 0$ $D^3 \sin 0 = -1$ $D^4 \sin 0 = 0$
$D \cos 0 = 0$ $D^2 \cos 0 = -1$ $D^3 \cos 0 = 0$ $D^4 \cos 0 = 1$
$\sin x = x - \frac{x^3}{1.2.3} + \frac{x^5}{1.2.3.4.5} \text{ \&c}$
$\cos x = 1 + \frac{x^2}{1.2} + \frac{x^4}{1.2.3.4}$

$D \tan x = D \frac{\sin x}{\cos x} = \frac{\cos x D \sin x - \sin x D \cos x}{\cos^2 x} =$
$\frac{\cos^2 + \sin^2}{\cos^2} = \frac{1}{\cos^2 x}$

$D^2 \tan x = \frac{2 \sin x}{\cos^3 x} = 2 \tan x D \tan x$
$D^3 \tan x = 2 \tan x D^2 \tan x + 2 (D \tan x)^2$
$D^4 \tan x = 2 \tan x D^3 \tan x + 6 D \tan x D^2 \tan x$
$D^n \tan x = $ [del]$\dots$[/del] [ins]$\sum \frac{n!}{m!(n-m)!} D^{n-m} \tan x D^m \tan x$[/ins]

$D \tan 0 = 1$ $D^2 \tan 0 = 0$ $D^3 \tan 0 = 2$ $D^4 \tan 0 = 0$ $D^5 \tan 0 = 16$
By Maclaurin $\tan x = x + \frac{1}{3}x^3 + \frac{2}{15}x^5 \text{ \&c}$
