[u]Art. 23[/u]. But I have lingered too long among enumerable multitudes. Let us go on to inquire what is the smallest possible multitude which is inenumerable.

Take the collection of Ms. If this collection be such that taking any one-to-one relation [u]r[/u] whatever, if every M is [u]r[/u] to an M it necessarily follows that every M is [u]r[/u]'d by an M, the collection of Ms thereby fulfills the definition of an enumerable collection. We can substitute a phrase for the letter [u]r[/u] in this statement and say, that to call the collection of Ms enumerable is the same as to assert that if every M [ins]in any order of arrangement[/ins] is immediately succeeded by another M, and that, [del]one[/del] [ins]an M[/ins] which does not [ins]immediately[/ins] succeed any other of the Ms, then every M immediately succeeds another M, [del]and there is some ring arrangement without any first. To say that if there be no last there can be no first, is to say the collection spoken of is enumerable.[/del]

To deny that the Ms are enumerable is, then, as much as to assert that there is a possible arrangement in which [del]there is a first and in which[/del] each M is immediately followed by another M which so follows no third M, and yet there is an absolutely first M which does not follow any M. If now we deny that the collection of Ms is enumerable but, at the same time, restrict it to including no individual that need not be included to make the collection inenumerable, we shall plainly have [del]a[/del] collection of the lowest order of multitude which any inenumerable collection can have. Such a collection I call [u]denumerable[/u]. To say, then, that the collection [ins]of Ms[/ins] is denumerable, is the same as to assert that it contains nothing except one particular object and except [ins]what is implied in the fact[/ins] that there is a one-to-one relation [u]r[/u] such that every M is [u]r[/u] to an M. This is a logical character; for it is the same as to say that [del]the theorem of transposed quantity does not hold good of it but that the Fermatean inference does. That is, if the collection of Ms is denumerable, every character which is true of a certain M, say M₀, and is also true of every M which is in a certain one-to-one relation to an M of which it is true, is necessarily true of every M of the collection.[/del]
