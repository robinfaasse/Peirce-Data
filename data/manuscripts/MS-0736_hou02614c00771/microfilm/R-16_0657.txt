[del]If a proposition has its antecedent false or its consequent true, it is true.[/del]

There are two convenient corollaries from this. The first is that

[del]a + b + c + b + a + c[/del]

[u]a + b + c + b + a + c[/u]

is necessarily true, so that

a + b + c = b + a + c.
