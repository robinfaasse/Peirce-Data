[u]b+a+a[/u].

(for this is a case of the proposition that if B, then [u]A+B[/u], since [u]a+a[/u] is necessarily true.) But if [del]b is true[/del] the truth of b may be written

[u]a+a+b[/u];

for if this is true b is true by the modus ponens, and if b is true this is true by the proposition just cited.
