$\therefore$ In general if $\Psi^{a,b} \bar{\bar{3}} 0$ $\Psi^a \bar{\bar{3}} 0$

Let us now take the premises
$$\Psi^{a,b} \bar{\bar{3}} 0 \qquad \text{Some } a \text{ is } b$$
$$b,c \bar{\bar{3}} 0 \qquad \text{No } b \text{ is } c$$

From the latter
$$b \bar{\bar{3}} b,0^c$$
$$\therefore \Psi^{a,0^c,b} \bar{\bar{3}} 0$$
$$\therefore \Psi^{a,0^c} \bar{\bar{3}} 0 \qquad \text{Some } a \text{ is not } c.$$
