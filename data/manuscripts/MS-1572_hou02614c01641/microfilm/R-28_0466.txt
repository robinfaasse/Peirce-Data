Indeed, in general, if
$$\begin{array}{c} \overline{\ \ } B, \\ \therefore \overline{\ \ } C, \end{array}$$
is a valid inference, so also is
$$\begin{array}{c} \overline{\ A \ } B, \\ \therefore \overline{\ A \ } C. \end{array}$$
For if from the truth of $A$, the truth of $B$ follows, since we
have seen that from the truth of $B$ the truth of $C$ follows,
we rightly conclude that from the truth of $A$ the truth of
$C$ follows.

Hence, it is evident that an antecedent may be in-
serted anywhere. The inference
$$\begin{array}{c} \overline{\ X \ } \\ \therefore \overline{\ X \ } \overline{\ Y \ } \end{array}$$
is an instance of this. For $\overline{\ X \ }$ means that, no matter
what $O$ may be
$$\overline{\ X \ } \overline{\ O \ }$$
And by inserting an antecedent we get
$$\overline{\ X \ } \overline{\ Y \ } \overline{\ O \ }.$$
But since $O$ may be anything, this gives
[del]$$\overline{\ X \ } \overline{\ Y \ }.$$[/del]
