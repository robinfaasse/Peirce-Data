I now pass to the results of substituting identical propositions
for premises in the various [del]kinds[/del] [ins]moods[/ins] of syllogism. This procedure
applied to the first figure gives nothing but repetitions of the
other premise in the conclusion, which shows how simple
and so to say pure from all admixture of special characters
these moods are.

It should be observed by the way that the only identical pro-
positions are,
$$\text{All } X \text{ is } X,$$
$$\text{No non-}X \text{ is } X,$$
$$\text{Some } X \text{ is } v\text{-}X.$$
The propositions, "No $X$ is non-$X$," and "Some $v\text{-}X$ is $X$," are for the
present purposes not to be regarded as identical ones, since they
depend on properties of the negative and the particular.

In the second figure, we have just now seen that [u]Camestres[/u] gives
the contraposition of $A$ into $E$, showing that it involves the first
property of the negative. It does not involve the second property [ins]for[/ins] [del]as[/del]
it can be reduced to the first figure without conversion; thus,

$$\begin{array}{c}
\text{\underline{Camestres}} \\
\text{All } M \text{ is } P, \\
\text{No } S \text{ is } P, \\
\hline \therefore \text{No } S \text{ is } M.
\end{array}
\qquad
\begin{array}{c}
\text{\underline{Reduction}} \\
\text{No not-}P \text{ is } M, \\
\text{All } S \text{ is not-}P, \\
\hline \therefore \text{No } S \text{ is } M.
\end{array}$$

[del]Baroko may be reduced[/del] in the same way. On the other hand [u]Cesare[/u]
and [u]Festino[/u] involve the second property of negation, as is shown
by such forms as,

$$\begin{array}{c}
\text{No } Y \text{ is } X, \\
\text{All } X \text{ is } X, \\
\hline \therefore \text{No } X \text{ is } Y
\end{array}
\qquad
\begin{array}{c}
\text{No non-}X \text{ is } X, \\
\text{All } Z \text{ is } X, \\
\hline \therefore \text{All } Z \text{ is non-non-}X.
\end{array}$$
