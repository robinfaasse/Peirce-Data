$$\psi^{n+1}(\psi^n + C) - B(\psi^n + C) + B(C-A) = 0$$

$$(\psi^{n+1} + C)(\psi^n + C) - (B+C)(\psi^n + C) + B(C-A) = 0$$

[del]$$\frac{u_{n+1}}{u_n} = \frac{\psi^{n+1} + C}{\psi^n + C} = \frac{1 + \frac{\psi^{n+1}}{C}}{1 + \frac{\psi^n}{C}}$$[/del]

$$(1 + \frac{\psi^{n+1}}{C})(1 + \frac{\psi^n}{C}) - (1 + \frac{B}{C})(1 + \frac{\psi^n}{C}) + B(1 - \frac{A}{C}) = 0$$

$$1 + \frac{\psi^n}{C} = [del]u_n[/del] [ins]u_{n+1}[/ins]$$

$$u_{n+2} - (1 + \frac{B}{C})u_{n+1} + B(1 - \frac{A}{C})u_n = 0$$

[del]$$u_n = C$$[/del] $$\alpha = \frac{1}{2}(1 + \frac{B}{C}) [del]\pm[/del] [ins]\left( -1 + \sqrt{1 - 4B \frac{1 - \frac{A}{C}}{(1 + \frac{B}{C})^2}} \right)[/ins]$$

$$u_n = C_1 \alpha^n + C_2 \beta^n$$

$$1 + \frac{\psi^n}{C} = \frac{1 + \mathcal{C} (\frac{\beta}{\alpha})^{n+1}}{1 + \mathcal{C} (\frac{\beta}{\alpha})^n}$$

[del]$$\frac{\beta}{\alpha} = 1 + \frac{(1 - \sqrt{1 - 4B \frac{1 - \frac{A}{C}}{(1 + \frac{B}{C})^2}} )}{2}$$[/del]

$$\frac{\beta}{\alpha} = \frac{1 - \sqrt{H}}{1 + \sqrt{H}} = \frac{1 + H - 2\sqrt{H}}{1 - H}$$
