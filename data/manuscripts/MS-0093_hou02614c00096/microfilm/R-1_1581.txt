[u]Functional Equations[/u]

The equation
$F(x, \phi \psi x, \phi \chi x) = 0$
where $\phi$ is the only unknown function is reducible to
$F(x, \phi x, \phi \omega x) = 0$
For it is only necessary to make $\phi \psi$ the unknown, say $v$. Then it become
$F(x, v x, v \psi^{-1} \chi x) = 0$
But this does not help much.
Put
$\psi x = u_t$
$\chi x = u_{t+1}$
$\phi \psi = v_t$
$\phi \chi x = v_{t+1}$

Then we shall have $\phi u_t = v_t$
and the equation $F(x, \phi \psi x, \phi \chi x) = 0$
will be
$F(x, \phi u_t, \phi u_{t+1}) = 0$
and eliminating $x$, we get an equation of differences

Linear functional equations like
$\phi \psi^n x + a \phi \psi^{n-1} x + b \phi \psi^{n-2} x + \text{etc} = X$
maybe so solved.
For let $\pi$ be such that $\pi \phi x = \phi \psi x$
Then
$(\pi^n + a \pi^{n-1} + b \pi^{n-2} + \text{etc} ) \phi x = X$
Then $m$ being a root of the corresponding algebraic equation
$(\pi - m) \phi x = X$

For example. Given $\phi(m^2 x) + a \phi(m x) + b \phi x = x^n$
The solution is
$\phi x = \frac{x^n}{m^{2n} + a m^n + b} + C_1 x^{\frac{\log \alpha}{\log m}} + C_2 x^{\frac{\log \beta}{\log m}}$
where $\alpha$ and $\beta$ are the roots of $\xi^2 + a \xi + b = 0$
