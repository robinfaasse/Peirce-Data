is any one valency, or if not one whether there
are any two valencies which we can attribute
to all undecomposable elements alike, so far
as we can [u]a priori[/u] ascertain. The other sense
is, what [del]is[/del] [ins]are[/ins] the lowest valencies which can be
attributed to the undecomposable elements,
as far as can be discovered [u]a priori[/u]. Now
[del]let[/del] taking the questions in the first sense,
