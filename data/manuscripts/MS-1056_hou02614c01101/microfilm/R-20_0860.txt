But if the series is infinite (that is, if $n = \infty$) the weight
of $\{M_{i-1} - M_{i}\}$ or $1 + \frac{1}{\delta + 1}$ is the same as the weight of
$\{M_{i} - M_{i+1}\}$ or $\frac{1}{\delta}$ and if $n$ is only moderately great
say [del]$\ge 5$[/del] this is sensibly the case. We may therefore
write for an approximation
$$\frac{1}{\delta} = 1 + \frac{1}{\delta + 1}$$
$$\delta + 1 = \delta(\delta + 1) + \delta$$
$$\delta(\delta + 1) = 1$$
$$\delta = \frac{1}{2}(\sqrt{5} - 1)$$

This number has a property which it will be convenient
to make use of. For since
$$\frac{1}{\delta} = \delta + 1 \text{ or } Q = 1 + Q^{-1}$$
we have
$$Q^{n+1} = Q^{n} + Q^{n-1}$$
