His IV, V, VI, are all included in the following, which involves nothing not involved in one of them:

Given any set of elements (alike or different) then extraneous to the set are two elements which in every respect in which the elements of the set are all alike (if any such respect there be) are unlike the elements of the set while in all other respects the two are unlike and one of them is in some respect [ins]or other[/ins] like any element of the set which [del]in all these respects (in which elements of the set differ)[/del] is unlike all the other elements [del]of the set.[/del]

If the set consists of repetitions of one element, the extraneous pair will be repetitions of the obverse thus satisfying his IV. If the set consists of a pair of unlike elements, since each of these is unlike the other in every respect in which they are unlike, one of the extraneous pair will [del]be[/del] in some respect in which they are unlike be like one and in some such respect like the other, satisfying his V. That VI is satisfied is obvious.

At first glance, my statement seems to require too much. For the pair [fig]four circles arranged in a square, top two open, bottom two filled[/fig] may satisfy V by [fig]two circles, top open, bottom filled[/fig] and may satisfy VI by [fig]four circles arranged in a square, top-left filled, top-right open, bottom-left open, bottom-right filled[/fig].
