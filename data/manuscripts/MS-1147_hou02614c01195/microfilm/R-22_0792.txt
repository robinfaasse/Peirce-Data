$A$ differs in value from $B$,
$B$ differs in value from $C$;
$\therefore C$ has the same value as $A$.

For a system of three values this inference does not hold but the following is valid, though not for any system of values greater than three:

$A$ differs in value from $B$;
$A$ differs in value from $C$;
$A$ differs in value from $D$;
$B$ differs in value from $C$;
$B$ differs in value from $D$;
$\therefore C$ has the same value as $D$.
