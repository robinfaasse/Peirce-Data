Insolubilia. [Is from in, not, and solu-bilis, capable of being taken to pieces, from solvo, to loose, from se-, [ins]apart,[/ins] [del]over[/del], and luo, to loose. The same root is in Gr. λύω, E. loose.]

A part of the Parva Logicalia, treating of certain difficult sophisms, is so called. The type of them is the following:

[u]This proposition is not true.[/u]

Is that proposition, which proclaims itself not true, and [del]asserts[/del] nothing more true, or not? Suppose, first, that it is true. Then, [ins]all that[/ins] what it asserts is true, [del]which is[/del] [ins]and it asserts[/ins] that it is not true. Ergo, it is not true. Besides, if it is true, it is true that it is true, and consequently, it is not [del]true[/del] [ins]true[/ins] that it is not true.

That it is not true is not true
The proposition is that it is not true
That it is not true is asserted in it
∴ Something asserted in it is not true
∴ It is not true
