$v_{lmn}$ = number so that branch 2 terminates differently branches 1 & 3 terminating alike

$w_{lmn}$ = [del]same number so that[/del] [ins]same number so that[/ins] branch 3 terminates differently from branches 1 & 2 which terminate alike

$t_{lmn}$ the number of ways with $c$ colors of coloring a three branch figure so shaped that [del]each[/del] the first region in each branch touches the first in each of the others, but after that each region touches only the preceding and following regions of the same branch, and there are $l, m, n$, regions in branches 1, 2, 3, and all the branches have their terminals of different colors.
