EXPLANATION OF SIGNS, &c.

$A : C = B : D$;

from which we obtain, by the preceding propositions,

$A + B : C + D = A - B : C - D = A : C = B : D$

$A + B : A - B = C + D : C - D$.

Two proportions, as

$A : B = C : D$

and

$E : F = G : H$,

may evidently be multiplied together term by term, and the result

$A \times E : B \times F = C \times G = D \times H$

is a new proportion.

Likewise, a proportion may be multiplied by itself any number of times in succession, and the squares, cubes, fourth powers, &c. of the terms form a new proportion. Thus, the proportion

$A : B = C : D$

gives

$A^2 : B^2 = C^2 : D^2$

$A^3 : B^3 = C^3 : D^3$

$A^4 : B^4 = C^4 : D^4$, &c. &c.
