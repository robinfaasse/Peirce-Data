Then $(\underline{a}\underline{d}) = (\{PR\}\{QR\})$. This plane contains a ray which contains P. Hence it contains P. In like manner, it contains Q and R. Hence
$(\underline{a}\underline{d}) = (PQR)$.

In like manner
$(\underline{b}\underline{c}) = (PQS)$

Now the two planes $(PQR)$ and $(PQS)$ contain a common ray, which is evidently $\{PQ\}$. Hence
$\{(\underline{a}\underline{d})(\underline{b}\underline{c})\} = \{PQ\}$.

Thus $\{[\underline{a}\underline{c}][\underline{b}\underline{d}]\} = \{(\underline{a}\underline{d})(\underline{b}\underline{c})\}$ Q.E.D.

This notation will be found in many cases a great aid [del]in thinking[/del]. The student must learn to use notations to think [u]in[/u], but he must not try to make the notation [del]think[/del] for him, if he wishes to push his reasonings far. Thinking is done by experimenting in the imagination. [del]The[/del] Notations are excellent things to experiment with; but still the experimentation requires intelligent supervision to come to much.
