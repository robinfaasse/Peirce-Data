From this row of numbers, which we will call the
Ms, we make a second row, which we will call the N's. The
first two Ns are 0, 1, the rest are formed by multiplying
the last by the first M not already used and adding to the
product the last N but one. Then the Ns are
0, 1, 4, 9, 22, 31, 53.
The last N is 53. N will always be the number of cards
in the pack. Reversing the order of the M's
1, 1, 2, 2, 4
will make no difference in the last N. Thus, the N's will be
0, 1, 1, 2, 5, 12, 53
Leave off the first M, and the last N will be the number of
