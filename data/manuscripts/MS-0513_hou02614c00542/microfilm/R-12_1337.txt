If [del]this[/del] no relation of this description supposes any description of object or pair of objects to exist except what is involved in the existence of $\delta$, then every relation formed by this [del]rule[/del] description of proceedure exists.

For example, because there is a relation in which every button stands to every button-hole it does not follow that for each button there is a button hole. But if the new relation is formed from the old one [ins]by[/ins] merely striking out some pairs or admitting any pairs of given description that may exist, every such relation is possible.
