This is convenient in writing, for example,
$$\Pi_{i}\Sigma_{j}\Sigma_{k}\Pi_{x}\Sigma_{y} \bar{a}_{i} + r_{ijk} \cdot b_{yj} (l_{kx} + s_{xy}).$$
Which will appears thus:
$$\breve{a}_{j} \ \acute{r} \ \breve{b}_{l \ \acute{s}} \ \bar{o}$$

But in the case before [del]u[/del][ins]u[/ins]s the heavy parenthesis is sufficient. We write
$$\Pi_{\beta}\Sigma_{\gamma} \infty \breve{b} [(\bar{\beta} + \beta r) \bar{j} 0] + \{ 0 \bar{j} \breve{b} \bar{j} [(\bar{\beta} + ([\gamma \cdot (\bar{\gamma} \bar{j} 1)] c)] \bar{j} 0 \} \cdot$$
$$\{ 0 \bar{j} \breve{b} \bar{j} [\bar{\beta} + ([\bar{\gamma} \cdot (\frac{1}{\bar{\gamma}} \bar{j} 1)] a)] \bar{j} \bar{c} \ \bar{j} 0 \}.$$
