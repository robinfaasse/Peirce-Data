If the object is to produce the simplest algebraic system, we [del]must[/del] [ins]may[/ins] use instead of 1, A, B, C, D, E, the operations g, h, i, j, k, l, defined as follows:

$g = \frac{1}{6} (1 + A + B + C + D + E)$ [del]so that $g \rho_{123}$[/del]
[del]$h = \frac{1}{6}$[/del] [del]$h = \frac{1}{6}$[/del] $= \frac{1}{6} (\rho_{123} + \rho_{231} + \rho_{312} + \rho_{132} + \rho_{321} + \rho_{213})$
$h = \frac{1}{6} (1 + C + D - A - B - E)$ so that $h \rho_{123} = \frac{1}{6} (\rho_{123} + \rho_{231} + \rho_{312} - \rho_{132} - \rho_{321} - \rho_{213})$
$i = \frac{1}{6} (2 \cdot 1 - C - D + 2A - B - E)$ so that $i \rho_{123} = \frac{1}{6} (2\rho_{123} - \rho_{231} - \rho_{312} + 2\rho_{132} - \rho_{321} - \rho_{213})$
$l = \frac{1}{6} (2 \cdot 1 - C - D - 2A + B + E)$ so that $l \rho_{123} = \frac{1}{6} (2\rho_{123} - \rho_{231} - \rho_{312} - 2\rho_{132} + \rho_{321} + \rho_{213})$
$j = \frac{1}{2\sqrt{3}} (C - D + B - E)$ so that $j \rho_{123} = \frac{1}{2\sqrt{3}} (\rho_{231} - \rho_{312} + \rho_{213} - \rho_{321})$
$k = \frac{1}{2\sqrt{3}} (-C + D + B - E)$ so that $k \rho_{123} = \frac{1}{2\sqrt{3}} (-\rho_{231} + \rho_{312} + \rho_{213} - \rho_{321})$
