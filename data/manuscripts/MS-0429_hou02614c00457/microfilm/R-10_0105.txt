The proof is simple enough. If [u]F x[/u] has the value [u]v[/u],
either [u]x[/u] has the value [u]v[/u], when [u]F x[/u] becomes [u]F v[/u] or [u]x[/u] has the
value [u]v[/u], so that, in any case, [u]F v[/u] + [u]x[/u] has the value [u]v[/u]; and
further, either [u]x[/u] has the value [u]v[/u], when [u]F x[/u] becomes [u]F f[/u] or
[u]x[/u] has the value [u]v[/u], so that, in any case, [u]F f[/u] + [u]x[/u] has the val-
ue [u]v[/u]. Consequently, if [u]F x[/u] has the value [u]v[/u], the composite
([u]F v[/u] + [u]x[/u]) , ([u]F f[/u] + [u]x[/u]) has the same value. But if [u]F x[/u] has the
value [u]f[/u], either [u]x[/u] has the value [u]v[/u], when [u]F x[/u] becomes [u]F v[/u], and
[u]F v[/u] + [u]x[/u] has the value [u]f[/u], or [u]x[/u] has the value [u]f[/u], when [u]F x[/u] becomes
[u]F f[/u], and [u]F f[/u] + [u]x[/u] has the value [u]f[/u]. Thus, if [u]F x[/u] has the
value [u]f[/u], one or other of the components of ([u]F v[/u] + [u]x[/u]) , ([u]F f[/u] + [u]x[/u])
has the value [u]f[/u], and again ([u]F v[/u] + [u]x[/u]) ([u]F f[/u] + [u]x[/u]) has the same value
as [u]F x[/u].
