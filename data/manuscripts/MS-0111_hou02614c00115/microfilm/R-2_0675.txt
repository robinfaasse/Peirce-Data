Formulae for Plane Triangles

[del]Let[/del] [ins]Put[/ins] $a+b+c = 2s$
$a' = s-a$
$b' = s-b$
$c' = s-c$

$\frac{1}{\tan\frac{1}{2}A} + \frac{1}{\tan\frac{1}{2}B} + \frac{1}{\tan\frac{1}{2}C} = \frac{1}{\tan\frac{1}{2}A\tan\frac{1}{2}B\tan\frac{1}{2}C}$

$a' \tan\frac{1}{2}A = b' \tan\frac{1}{2}B = c' \tan\frac{1}{2}C$

$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$

$\text{Area} = T = \sqrt{s a' b' c'} = \frac{b' c'}{\tan\frac{1}{2}A} = bc \sin A$

<u>Inscribed and Escribed circles</u>

$r = \frac{T}{s} = s \tan\frac{1}{2}A \tan\frac{1}{2}B \tan\frac{1}{2}C = a' \tan\frac{1}{2}A$

$r_a = \frac{T}{a'} = s \tan\frac{1}{2}A$

$\frac{s}{r_a} + \frac{s}{r_b} + \frac{s}{r_c} = \frac{s^3}{r_a r_b r_c} = \frac{s}{r}$
