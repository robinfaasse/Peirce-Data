1. By a [u]hec[/u] is to be understood any such object such that if there is any real possibility of its having any character it really has that character; and if it has not a given character, it has the negative of that character. Hence, if [u]a[/u] is a hec, and [u]b[/u] is a hec, and [u]a[/u] is [u]b[/u], it follows that [u]b[/u] is [u]a[/u]. For to say that '[u]a[/u] is [u]b[/u]' means that [u]a[/u] has whatever character [u]b[/u] has. Now if [del]there[/del] [ins][u]b[/u][/ins] is any character that [u]b[/u] has not, [u]b[/u] has the negative of that character and consequently [u]a[/u] has the negative of that character.
